Description (GitHub "About", <= 350 characters):
Tiny portable photo viewer & editor for Windows XP to 11 - one Kadr.exe under 1 MB, no installer. Zoom, slideshow, crop with live frame, pen/highlighter/shapes/text, adjustments, print preview (fit/fill/stretch), export, DjVu/TIFF/PSD/QOI and more, light/dark/auto theme, 30 languages. Native Zig + Win32/GDI+, GPL-3.0.
