# Kadr

**מציג ועורך תמונות מהיר, זעיר ונייד ל-Windows — מ-Windows XP ועד Windows 11, בקובץ `Kadr.exe` יחיד שגודלו פחות מ-1 MB.**

Kadr הוא יישום Win32/GDI+ מקורי שנכתב ב-[Zig](https://ziglang.org/). בלי תוכנת התקנה, בלי .NET, בלי Electron, בלי Node.js: מעתיקים את `Kadr.exe` לכל מקום ומפעילים. ההגדרות נשמרות בקובץ `Kadr.ini` לצד התוכנה (נייד — שום דבר לא נכתב לרישום או ל-AppData).

## תכונות

- **מציג** — פתיחת תמונות, דפדוף בתיקייה (מקשי החצים, קודמת/הבאה), מצגת, מסך מלא, זום חלק (התאמה, 1:1, גלגלת העכבר במיקום הסמן, ערכים מוקלדים כמו `125%`, `37,5%` או `200×`), הזזת התמונה, הפעלת GIF מונפש, TIFF ו-DjVu מרובי עמודים, כיוון אוטומטי לפי EXIF.
- **עורך** — חיתוך עם מסגרת חיה ויחסי ממדים מוגדרים מראש (חופשי, 1:1, 4:3, 3:4, 3:2, 2:3, 16:9, A4 לאורך/לרוחב); עט, מרקר הדגשה, מחק, קו, חץ, מלבן וטקסט; ביטול/חזרה; סיבוב והיפוך; בהירות, ניגודיות, רוויה ושחור-לבן. השינויים נשמרים בזיכרון עד שתשמרו.
- **הדפסה** — תצוגה מקדימה חיה להדפסה עם גודל נייר, כיוון, קנה מידה (התאמה / מילוי (חיתוך) / מתיחה (עמוד שלם) / 100% / אחוז מותאם / רוחב או גובה ב-mm), שוליים, מיקום, צבע או גווני אפור.
- **כלי קבצים** — שמירה (סיבוב), שמירה בשם, ייצוא / דחיסה (PNG, JPEG, BMP, TIFF, GIF) עם שינוי גודל והערכת גודל, העתקת התמונה או הנתיב ללוח, שינוי שם, העברה לסל המיחזור או מחיקה לצמיתות, הצגה בתיקייה, הגדרה כטפט שולחן העבודה.
- **תבניות** — PNG, JPEG/JFIF, BMP/DIB, GIF, TIFF, DjVu, ICO, WMF/EMF, TGA, PCX, PSD (תמונה ממוזגת), PBM/PGM/PPM/PNM, QOI.
- **30 שפות ממשק** — שפת Windows מזוהה אוטומטית (ברירת המחדל היא אנגלית) וניתן לשנות אותה מהתפריט; פריסה מימין לשמאל לערבית, עברית, אורדו ופרסית.
- **ערכות נושא** — בהירה, כהה או אוטומטית (עוקבת אחר מצב האפליקציות של Windows ומתחלפת בזמן אמת).
- **קטן** — קובץ `Kadr.exe` אחד שגודלו פחות מ-1 MB.
- **Windows XP ואילך** — פועל מ-Windows XP SP3 (x86) ועד Windows 10/11.

## הורדה / התקנה

1. הורידו את `Kadr.exe` מ[דף הגרסאות](https://github.com/snakex21/kadr/releases) (עותק מוכן של `Kadr.exe` נשמר גם בתיקיית השורש של המאגר).
2. שימו אותו בכל תיקייה שיש לכם הרשאת כתיבה אליה (למשל דיסק און קי) והפעילו אותו. אין תוכנת התקנה.
3. עבור קובצי DjVu, השאירו את התיקייה `deps\djvu\` מהמאגר לצד `Kadr.exe`.

כדי לפתוח תמונות בלחיצה כפולה, השתמשו ב-Windows באפשרות *פתח באמצעות → בחר אפליקציה אחרת* על תמונה ובחרו ב-`Kadr.exe`.

**דרישות:** Windows XP SP3 x86 ומעלה (גם Windows 10/11 מתאימים). שום דבר נוסף.

> מפענח ה-DjVu הוא הגרסה הישנה DjVuLibre 3.5.27 — פתחו רק קובצי DjVu שאתם סומכים עליהם (פרטים ב-`THIRD-PARTY.txt`).

## שימוש

- **פתיחת** תמונה: באמצעות **פתח** (Ctrl+O), בגרירת קובץ אל החלון או בהעברתו בשורת הפקודה: `Kadr.exe photo.jpg`.
- **דפדוף** בתיקייה: באמצעות ← / → או כפתורי החצים; המונה מציג את המיקום (למשל `1 / 3`). החזיקו מקש חץ לחוץ כדי לדפדף במהירות.
- **זום**: בגלגלת העכבר (מתקרב במיקום הסמן), `+` / `−`, **התאם** (Home), **1:1** (`1`) או הקלידו ערך בשדה הזום ולחצו Enter. גררו את התמונה כדי להזיז אותה.
- **סיבוב**: באמצעות R / L. מסתובבת התצוגה בלבד; **שמור** (Ctrl+S) כותב את הסיבוב לקובץ.
- **עוד (…)** פותח את התפריט עם כל פעולות הקבצים, העורך, ההדפסה, המצגת, המסך המלא, העזרה, *בדיקת עדכונים…*, *ערכת נושא* ו*שפה*.
- **בדיקת עדכונים…** רק פותח את דף הגרסאות של הפרויקט ב-GitHub בדפדפן שלכם — Kadr עצמו אף פעם לא מתחבר לאינטרנט.

## עורך

פותחים את העורך באמצעות **Edit** ("עריכה", Ctrl+E). כל השינויים נשמרים בזיכרון; הקובץ המקורי לא משתנה עד שתשמרו.

- **חיתוך** — מסגרת חיה עם שמונה ידיות; גררו את המסגרת או את הידיות, הקלידו X / Y / רוחב / גובה מדויקים בפיקסלים, או בחרו יחס ממדים מוגדר מראש (חופשי, ריבוע 1:1, 4:3, 3:4, 3:2 (4×6 לרוחב), 2:3, 16:9, A4 לאורך, A4 לרוחב). האזור שמחוץ למסגרת מוחשך; **חתוך** (Enter) חותך אותו, ו-**Whole photo** (התמונה כולה) מאפס את המסגרת.
- **ציור** — עט, מרקר הדגשה שקוף למחצה, מחק (מוחק רק ציורים וטקסט, לעולם לא את התמונה), קו ישר, חץ, מלבן וטקסט, עם עשרה צבעים ועובי מתכוונן.
- **תמונה** — ביטול / חזרה, סיבוב ב-90° שמאלה או ימינה, שיקוף אופקי או אנכי, איפוס הכול.
- **צבע ותאורה** — בהירות, ניגודיות, רוויה ושחור-לבן.
- **סיום** — *החל* מחזיר את התמונה הערוכה למציג, *Save as…* שומר עותק בשם חדש, *Print…* עובר ישירות לתצוגה המקדימה להדפסה, *ביטול* (Esc) מבטל את השינויים.

## הדפסה

**הדפס** (Ctrl+P) פותח תצוגה מקדימה חיה של הגיליון. בחרו מדפסת, נייר (A3–A6, B4/B5, Letter, Legal, Executive, Tabloid, גודלי צילום 10×15, 13×18, 15×20, 20×25 cm, 4×6, 5×7, 8×10 in, גודל מותאם או זה של המדפסת), כיוון וצבע או גווני אפור. הכיוון מותאם לתמונה אוטומטית עד שתשנו אותו.

מצבי קנה מידה:

| מצב | מה הוא עושה |
|---|---|
| **התאם** | התמונה כולה נכנסת בתוך השוליים; היחס נשמר, וייתכנו פסים לבנים בשני צדדים. |
| **מילוי / חיתוך** | התמונה מכסה את כל אזור ההדפסה; היחס נשמר והקצוות החורגים נחתכים. |
| **Stretch (whole page)** (מתיחה על פני העמוד כולו) | התמונה נמתחת בדיוק על אזור ההדפסה — בלי פסים לבנים, אבל היחס **לא** נשמר. |
| **100% · גודל אמיתי (96 DPI)** | פיקסל אחד = 1/96 אינץ'. |
| **אחוז מותאם** | 0.1–1000% ביחס ל-96 DPI (100% = הגודל שלמעלה). |
| **רוחב (mm)** / **גובה (mm)** | רוחב או גובה פיזיים מדויקים; הצד השני נקבע לפי היחס. |

**מתקדם ▸** מוסיף גודל נייר מותאם, שוליים ומיקום מדויק על הגיליון (או גררו את התמונה בתצוגה המקדימה; *מרכז* מחזיר אותה לאמצע). הקו האפור מראה את הגבול החומרתי של המדפסת. מצב קנה המידה האחרון שנבחר נשמר ב-`Kadr.ini`.

## ערכות נושא

**עוד (…) → ערכת נושא** מציע **בהיר**, **כהה** ו**אוטומטי** (ברירת המחדל).

- **אוטומטי** עוקב אחר *מצב האפליקציות* של Windows (הגדרות → התאמה אישית → צבעים, הערך `AppsUseLightTheme`) ומתחלף בזמן אמת כשמשנים אותו ב-Windows. במערכות שאין בהן הגדרה זו (Windows XP, Vista, 7, 8) אוטומטי פירושו בהיר.
- ערכת הנושא חלה על החלון הראשי, סרגל הכלים, הכפתורים והסמלים, העורך, התצוגה המקדימה להדפסה ותיבות הדו-שיח של Kadr עצמו. במצב כהה רקע התמונה אפור כהה, וב-Windows 10/11 גם שורות הכותרת והתפריטים הקופצים כהים.
- כמה רכיבים מקוריים של Windows שומרים על מראה המערכת: תיבות ההודעה (עזרה, אישורים), תיבות הדו-שיח המערכתיות פתיחה / שמירה / הדפסה וידיות המחוונים.

## הגדרות (Kadr.ini)

כל ההגדרות נשמרות בקובץ `Kadr.ini` לצד `Kadr.exe`. אם התיקייה מוגנת מפני כתיבה, Kadr מודיע שלא ניתן לשמור את ההגדרות.

</div>

```ini
[General]
Language=en      ; pl, en, es, fr, de, pt, ru, uk, it, nl, cs, hu, ro, tr, el, ar, he, hi, bn, ur, zh, ja, ko, id, vi, th, fa, ta, te, mr
Theme=auto       ; auto, light or dark
[Print]
Scale=fit        ; fit, fill, stretch, actual, percent, width or height
```

<div dir="rtl">

את השפה אפשר לבחור גם דרך **עוד (…) → שפה**; השינוי ייכנס לתוקף לאחר הפעלה מחדש של Kadr. ערכת הנושא מוחלת מיד.

שפות הממשק: Polski, English, Español, Français, Deutsch, Português, Русский, Українська, Italiano, Nederlands, Čeština, Magyar, Română, Türkçe, Ελληνικά, العربية, עברית, हिन्दी, বাংলা, اردو, 中文, 日本語, 한국어, Bahasa Indonesia, Tiếng Việt, ไทย, فارسی, தமிழ், తెలుగు, मराठी.

## בנייה מקוד המקור

דרישות: [Zig 0.11.0](https://ziglang.org/download/0.11.0/zig-windows-x86_64-0.11.0.zip) מחולץ אל `tools\zig-windows-x86_64-0.11.0\` (הארכיון אינו חלק מהמאגר; ה-SHA-256 שלו מופיע ב-`THIRD-PARTY.txt`).

</div>

```bat
build.cmd
```

<div dir="rtl">

התוצאה היא `Kadr.exe` (יעד `x86-windows.xp`, Pentium III, `ReleaseSmall`) עם כותרת PE תואמת XP. יצירה מחדש של הסמל: `tools\build_icon.cmd` (Pillow + windres/objcopy).

Kadr מקושר רק לספריות שקיימות ב-Windows XP. תכונות חדשות יותר (שורות כותרת כהות, תפריטים ופקדים כהים) נטענות בזמן ריצה באמצעות `LoadLibrary` / `GetProcAddress` ומדולגות במערכות ישנות יותר.

## הרצת בדיקות

- חבילות הבדיקה נמצאות בתיקיות משנה של `tests\` (`editor-check`, `print-options`, `loader-check`, `image-check`, `codec-check`, `render-check`, `export-check`); כל אחת מופעלת באמצעות ה-`check.cmd` שלה, שבונה ומריץ רתמות בדיקה ב-Zig. `tests\editor-check\check.cmd` מריץ את בדיקות החלון הראשי (כולל בדיקות הגדרת ערכת הנושא ובחירתה), את בדיקות העורך, את בדיקת כיסוי השפות ובנייה מועמדת ל-x86/XP; `tests\print-options\check.cmd` מריץ את בדיקות ההדפסה והפריסה.
- ניתן להריץ בדיקות יחידה של מודולים בודדים עם `zig test`, למשל `zig test src\toolbar.zig`, `src\navigation.zig`, `src\image.zig`, `src\zoom.zig`, `src\theme.zig` (עם אותו יעד ואותם דגלי include כמו ב-`check.cmd`).
- סקריפטי עזר ב-Python 3: `python tests\i18n-check\run.py` (בחירת שפה), `python tests\locale_coverage.py` (כל מחרוזות הממשק נמצאות בקטלוג עבור 30 שפות), `python tests\audit_xp.py` (בדיקת הייבוא והכותרת של `Kadr.exe` לתאימות XP), `tests\measure_print.py`, `tests\tooltip_probe.py`, `tests\shot.py`.
- `tests\generate_fixtures.py` יוצר תמונות בדיקה (דורש Pillow); הוא משמש לפיתוח בלבד ולעולם לא את `Kadr.exe`.
