# Kadr

**Windows साठी वेगवान, अगदी लहान आणि पोर्टेबल फोटो दर्शक व संपादक — Windows XP पासून Windows 11 पर्यंत, 1 MB पेक्षा लहान असलेल्या एकाच `Kadr.exe` मध्ये.**

Kadr हे [Zig](https://ziglang.org/) मध्ये लिहिलेले नेटिव्ह Win32/GDI+ ॲप्लिकेशन आहे. इन्स्टॉलर नाही, .NET नाही, Electron नाही, Node.js नाही: `Kadr.exe` कुठेही कॉपी करा आणि चालवा. सेटिंग्ज प्रोग्रामशेजारी `Kadr.ini` मध्ये जतन होतात (पोर्टेबल — रजिस्ट्रीमध्ये किंवा AppData मध्ये काहीही लिहिले जात नाही).

## वैशिष्ट्ये

- **दर्शक** — फोटो उघडणे, फोल्डरमधील चित्रे पाहणे (बाण कळा, मागील/पुढील), स्लाइड शो, पूर्ण पडदा, सहज झूम (बसवा, 1:1, कर्सरच्या ठिकाणी माउस व्हील, `125%`, `37,5%` किंवा `200×` सारखी टाइप केलेली मूल्ये), चित्र सरकवणे, ॲनिमेटेड GIF प्ले करणे, अनेक पानांचे TIFF आणि DjVu, स्वयंचलित EXIF दिशा.
- **संपादक** — थेट फ्रेम आणि तयार गुणोत्तरांसह क्रॉप (मुक्त, 1:1, 4:3, 3:4, 3:2, 2:3, 16:9, A4 उभी/आडवी); पेन, हायलायटर, खोडरबर, रेषा, बाण, आयत आणि मजकूर; पूर्ववत/पुन्हा करा; फिरवणे आणि उलटणे; उजळपणा, कॉन्ट्रास्ट, संपृक्तता आणि कृष्णधवल. तुम्ही जतन करेपर्यंत बदल मेमरीमध्येच राहतात.
- **मुद्रण** — कागदाचा आकार, दिशा, प्रमाण (बसवा / भरा (कापा) / Stretch (संपूर्ण पान) / 100% / स्वतःची % / mm मध्ये रुंदी किंवा उंची), समास, स्थान, रंगीत किंवा करड्या छटांसह थेट मुद्रण पूर्वावलोकन.
- **फाइल साधने** — जतन (फिरवणे), या नावाने जतन, निर्यात / संकुचन (PNG, JPEG, BMP, TIFF, GIF) आकार बदलणे आणि आकाराच्या अंदाजासह, चित्र किंवा मार्ग क्लिपबोर्डवर कॉपी करणे, नाव बदलणे, रीसायकल बिनमध्ये पाठवणे किंवा कायमचे हटवणे, फोल्डरमध्ये दाखवणे, डेस्कटॉप वॉलपेपर म्हणून ठेवणे.
- **फॉरमॅट** — PNG, JPEG/JFIF, BMP/DIB, GIF, TIFF, DjVu, ICO, WMF/EMF, TGA, PCX, PSD (एकत्रित चित्र), PBM/PGM/PPM/PNM, QOI.
- **30 इंटरफेस भाषा** — Windows ची भाषा आपोआप ओळखली जाते (ती उपलब्ध नसल्यास इंग्रजी वापरली जाते) आणि मेनूमधून बदलता येते; अरबी, हिब्रू, उर्दू आणि फारसीसाठी उजवीकडून डावीकडे मांडणी.
- **थीम** — फिकट, गडद किंवा स्वयंचलित (Windows च्या ॲप मोडनुसार चालते, लगेच बदलते).
- **लहान** — 1 MB पेक्षा लहान एकच `Kadr.exe`.
- **Windows XP आणि नंतरच्या आवृत्त्या** — Windows XP SP3 (x86) पासून Windows 10/11 पर्यंत चालते.

## डाउनलोड / इन्स्टॉलेशन

1. [Releases पानावरून](https://github.com/snakex21/kadr/releases) `Kadr.exe` डाउनलोड करा (रिपॉझिटरीच्या मूळ फोल्डरमध्येही तयार `Kadr.exe` ठेवलेले आहे).
2. ज्या फोल्डरमध्ये तुम्ही लिहू शकता अशा कोणत्याही फोल्डरमध्ये (उदा. USB स्टिकवर) ते ठेवा आणि चालवा. कोणताही इन्स्टॉलर नाही.
3. DjVu फाइल्ससाठी रिपॉझिटरीमधील `deps\djvu\` फोल्डर `Kadr.exe` शेजारी ठेवा.

डबल-क्लिकने चित्रे उघडण्यासाठी, एखाद्या चित्रावर Windows चे *यासह उघडा → दुसरे ॲप निवडा* वापरा आणि `Kadr.exe` निवडा.

**आवश्यकता:** Windows XP SP3 x86 किंवा नवीन (Windows 10/11 वरही चालते). इतर काहीही लागत नाही.

> DjVu डीकोडर जुना DjVuLibre 3.5.27 आहे — फक्त विश्वासार्ह DjVu फाइल्सच उघडा (तपशील `THIRD-PARTY.txt` मध्ये).

## वापर

- **उघडा** बटणाने (Ctrl+O), फाइल विंडोवर ओढून किंवा कमांड लाइनवर देऊन चित्र **उघडा**: `Kadr.exe photo.jpg`.
- ← / → किंवा बाण बटणांनी फोल्डरमधील चित्रे **पाहा**; काउंटर स्थान दाखवतो (उदा. `1 / 3`). पटकन पुढे जाण्यासाठी बाण कळ दाबून ठेवा.
- माउस व्हीलने (कर्सरच्या ठिकाणी झूम होते), `+` / `−`, **बसवा** (Home), **1:1** (`1`) वापरून **झूम करा** किंवा झूम क्षेत्रात मूल्य टाइप करून Enter दाबा. चित्र सरकवण्यासाठी ते ओढा.
- R / L ने **फिरवा**. फक्त दृश्य फिरते; **जतन करा** (Ctrl+S) फिरवलेली दिशा फाइलमध्ये लिहिते.
- **अधिक (…)** सर्व फाइल क्रिया, संपादक, मुद्रण, स्लाइड शो, पूर्ण पडदा, मदत, *अद्यतने तपासा…*, *थीम* आणि *भाषा* असलेला मेनू उघडते.
- **अद्यतने तपासा…** फक्त प्रकल्पाचे GitHub रिलीज पान तुमच्या वेब ब्राउझरमध्ये उघडते — Kadr स्वतः कधीही इंटरनेटशी जोडले जात नाही.

## संपादक

**Edit** (Ctrl+E) ने संपादक उघडा. सर्व बदल मेमरीमध्ये ठेवले जातात; तुम्ही जतन करेपर्यंत मूळ फाइलला हात लावला जात नाही.

- **क्रॉप** — आठ हँडल असलेली थेट फ्रेम; फ्रेम किंवा तिची हँडल ओढा, पिक्सेलमध्ये अचूक X / Y / रुंदी / उंची टाइप करा, किंवा तयार गुणोत्तर निवडा (मुक्त, चौरस 1:1, 4:3, 3:4, 3:2 (4×6 आडवी), 2:3, 16:9, A4 उभी, A4 आडवी). फ्रेमबाहेरचा भाग गडद होतो; **क्रॉप** (Enter) तो कापून टाकते आणि **Whole photo** (संपूर्ण फोटो) फ्रेम पूर्वस्थितीत आणते.
- **रेखाटन** — पेन, अर्धपारदर्शक हायलायटर, खोडरबर (फक्त रेखाटने आणि मजकूर पुसतो, फोटो कधीच नाही), सरळ रेषा, बाण, आयत आणि मजकूर, दहा रंग आणि बदलता येणारी जाडी.
- **चित्र** — पूर्ववत / पुन्हा करा, 90° डावीकडे किंवा उजवीकडे फिरवा, आडवे किंवा उभे आरशासारखे उलटा, सर्व रीसेट करा.
- **रंग आणि प्रकाश** — उजळपणा, कॉन्ट्रास्ट, संपृक्तता आणि कृष्णधवल.
- **पूर्ण करणे** — *लागू करा* संपादित चित्र दर्शकाकडे परत पाठवते, *Save as…* (या नावाने जतन करा) नवीन नावाने प्रत जतन करते, *Print…* (मुद्रित करा) थेट मुद्रण पूर्वावलोकनात नेते, *रद्द करा* (Esc) बदल टाकून देते.

## मुद्रण

**मुद्रित करा** (Ctrl+P) कागदाचे थेट पूर्वावलोकन उघडते. प्रिंटर, कागद (A3–A6, B4/B5, Letter, Legal, Executive, Tabloid, फोटो आकार 10×15, 13×18, 15×20, 20×25 cm, 4×6, 5×7, 8×10 in, स्वतःचा किंवा प्रिंटरचा स्वतःचा आकार), दिशा आणि रंगीत किंवा करड्या छटा निवडा. तुम्ही बदलेपर्यंत दिशा आपोआप चित्रानुसार ठरते.

प्रमाण मोड:

| मोड | काय करतो |
|---|---|
| **बसवा** | संपूर्ण चित्र समासांच्या आत बसते; प्रमाण राखले जाते, दोन बाजूंना पांढरी जागा उरू शकते. |
| **भरा / कापा** | चित्र संपूर्ण मुद्रणयोग्य भाग व्यापते; प्रमाण राखले जाते आणि बाहेर जाणाऱ्या कडा कापल्या जातात. |
| **Stretch (whole page)** | चित्र अचूक मुद्रणयोग्य भागाइतके ताणले जाते — पांढऱ्या पट्ट्या नाहीत, पण प्रमाण राखले **जात नाही**. |
| **100% · प्रत्यक्ष आकार (96 DPI)** | एक पिक्सेल = 1/96 इंच. |
| **स्वतःची टक्केवारी** | 96 DPI च्या तुलनेत 0.1–1000% (100% = वरील आकार). |
| **रुंदी (mm) / उंची (mm)** | अचूक प्रत्यक्ष रुंदी किंवा उंची; दुसरी बाजू प्रमाणानुसार ठरते. |

**प्रगत ▸** स्वतःचा कागद आकार, समास आणि कागदावरील अचूक स्थान जोडते (किंवा पूर्वावलोकनात चित्र ओढा; *मध्यभागी* ते पुन्हा मध्यावर आणते). करडी रेषा प्रिंटरची हार्डवेअर मर्यादा दाखवते. शेवटी निवडलेला प्रमाण मोड `Kadr.ini` मध्ये लक्षात ठेवला जातो.

## थीम

**अधिक (…) → थीम** मध्ये **फिकट**, **गडद** आणि **स्वयंचलित** (डीफॉल्ट) पर्याय आहेत.

- **स्वयंचलित** Windows च्या *ॲप मोड* नुसार चालते (सेटिंग्ज → वैयक्तिकरण → रंग, `AppsUseLightTheme` मूल्य) आणि तुम्ही Windows मध्ये तो बदलताच लगेच बदलते. ही सेटिंग नसलेल्या प्रणालींवर (Windows XP, Vista, 7, 8) स्वयंचलित म्हणजे फिकट.
- थीम मुख्य विंडो, टूलबार, बटणे आणि आयकॉन, संपादक, मुद्रण पूर्वावलोकन आणि Kadr चे स्वतःचे संवाद यांना लागू होते. गडद मोडमध्ये चित्राची पार्श्वभूमी गडद करडी असते आणि Windows 10/11 वर शीर्षक पट्ट्या व पॉपअप मेनूही गडद होतात.
- Windows चे काही नेटिव्ह भाग प्रणालीचेच रूप ठेवतात: संदेश पेट्या (मदत, पुष्टीकरणे), उघडा / जतन करा / मुद्रित करा हे प्रणाली संवाद आणि स्लायडरची बटणे.

## सेटिंग्ज (Kadr.ini)

सर्व सेटिंग्ज `Kadr.exe` शेजारी `Kadr.ini` मध्ये जतन होतात. फोल्डर फक्त-वाचनीय असल्यास, सेटिंग्ज जतन करता येत नाहीत असे Kadr सांगते.

```ini
[General]
Language=en      ; pl, en, es, fr, de, pt, ru, uk, it, nl, cs, hu, ro, tr, el, ar, he, hi, bn, ur, zh, ja, ko, id, vi, th, fa, ta, te, mr
Theme=auto       ; auto, light or dark
[Print]
Scale=fit        ; fit, fill, stretch, actual, percent, width or height
```

भाषा **अधिक (…) → भाषा** मधूनही निवडता येते; बदल Kadr पुन्हा सुरू केल्यानंतर लागू होतो. थीम लगेच लागू होते.

इंटरफेस भाषा: Polski, English, Español, Français, Deutsch, Português, Русский, Українська, Italiano, Nederlands, Čeština, Magyar, Română, Türkçe, Ελληνικά, العربية, עברית, हिन्दी, বাংলা, اردو, 中文, 日本語, 한국어, Bahasa Indonesia, Tiếng Việt, ไทย, فارسی, தமிழ், తెలుగు, मराठी.

## सोर्स कोडमधून बिल्ड करणे

आवश्यकता: `tools\zig-windows-x86_64-0.11.0\` मध्ये अनपॅक केलेले [Zig 0.11.0](https://ziglang.org/download/0.11.0/zig-windows-x86_64-0.11.0.zip) (हे संग्रहण रिपॉझिटरीचा भाग नाही; त्याचा SHA-256 `THIRD-PARTY.txt` मध्ये आहे).

```bat
build.cmd
```

परिणाम म्हणजे XP-सुसंगत PE हेडर असलेले `Kadr.exe` (लक्ष्य `x86-windows.xp`, Pentium III, `ReleaseSmall`). आयकॉन पुन्हा तयार करण्यासाठी: `tools\build_icon.cmd` (Pillow + windres/objcopy).

Kadr फक्त Windows XP वर उपलब्ध असलेल्या लायब्ररींशीच लिंक होते. नवीन वैशिष्ट्ये (गडद शीर्षक पट्ट्या, गडद मेनू आणि नियंत्रणे) रन टाइमला `LoadLibrary` / `GetProcAddress` ने लोड केली जातात आणि जुन्या प्रणालींवर वगळली जातात.

## चाचण्या चालवणे

- चाचणी संच `tests\` च्या उपफोल्डरमध्ये आहेत (`editor-check`, `print-options`, `loader-check`, `image-check`, `codec-check`, `render-check`, `export-check`); प्रत्येक संच त्याच्या `check.cmd` ने सुरू होतो, जो Zig चाचणी हार्नेस बिल्ड करून चालवतो. `tests\editor-check\check.cmd` मुख्य विंडोच्या चाचण्या (थीम सेटिंग आणि थीम निश्चितीच्या चाचण्यांसह), संपादकाच्या चाचण्या, भाषा-व्याप्ती तपासणी आणि x86/XP उमेदवार बिल्ड चालवतो; `tests\print-options\check.cmd` मुद्रण आणि मांडणीच्या चाचण्या चालवतो.
- स्वतंत्र मॉड्यूलमधील युनिट चाचण्या `zig test` ने चालवता येतात, उदा. `zig test src\toolbar.zig`, `src\navigation.zig`, `src\image.zig`, `src\zoom.zig`, `src\theme.zig` (`check.cmd` मधील तेच लक्ष्य आणि include फ्लॅग वापरून).
- Python 3 सहायक स्क्रिप्ट: `python tests\i18n-check\run.py` (भाषा निवड), `python tests\locale_coverage.py` (सर्व UI मजकूर 30 भाषांसाठी कॅटलॉगमध्ये आहेत का), `python tests\audit_xp.py` (`Kadr.exe` चे XP इम्पोर्ट/हेडर ऑडिट), `tests\measure_print.py`, `tests\tooltip_probe.py`, `tests\shot.py`.
- `tests\generate_fixtures.py` चाचणी चित्रे तयार करतो (Pillow आवश्यक); तो फक्त विकासासाठी वापरला जातो, `Kadr.exe` कधीही त्याचा वापर करत नाही.
