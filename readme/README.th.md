# Kadr

**โปรแกรมดูและแก้ไขรูปภาพสำหรับ Windows ที่รวดเร็ว เล็กจิ๋ว และพกพาได้ — ตั้งแต่ Windows XP จนถึง Windows 11 ในไฟล์ `Kadr.exe` เพียงไฟล์เดียวที่มีขนาดไม่ถึง 1 MB**

Kadr เป็นแอปพลิเคชัน Win32/GDI+ แบบเนทีฟที่เขียนด้วย [Zig](https://ziglang.org/) ไม่มีตัวติดตั้ง ไม่ต้องใช้ .NET, Electron หรือ Node.js: เพียงคัดลอก `Kadr.exe` ไปไว้ที่ใดก็ได้แล้วเปิดใช้งาน การตั้งค่าจะเก็บไว้ใน `Kadr.ini` ข้างตัวโปรแกรม (พกพาได้ — ไม่มีการเขียนข้อมูลใด ๆ ลงในรีจิสทรีหรือ AppData)

## คุณสมบัติ

- **โปรแกรมดูภาพ** — เปิดรูปภาพ เลื่อนดูภาพในโฟลเดอร์ (ปุ่มลูกศร ก่อนหน้า/ถัดไป) สไลด์โชว์ เต็มหน้าจอ ซูมได้อย่างลื่นไหล (พอดี, 1:1, ล้อเมาส์ ณ ตำแหน่งเคอร์เซอร์, พิมพ์ค่าเอง เช่น `125%`, `37,5%` หรือ `200×`) ลากเพื่อเลื่อนภาพ เล่น GIF แบบเคลื่อนไหว TIFF และ DjVu หลายหน้า และหมุนภาพตาม EXIF โดยอัตโนมัติ
- **ตัวแก้ไข** — ครอบตัดด้วยกรอบแบบสดและสัดส่วนสำเร็จรูป (อิสระ, 1:1, 4:3, 3:4, 3:2, 2:3, 16:9, A4 แนวตั้ง/แนวนอน); ปากกา ปากกาเน้นข้อความ ยางลบ เส้นตรง ลูกศร สี่เหลี่ยม และข้อความ; เลิกทำ/ทำซ้ำ; หมุนและพลิก; ความสว่าง ความเปรียบต่าง ความอิ่มสี และขาวดำ การเปลี่ยนแปลงจะอยู่ในหน่วยความจำจนกว่าคุณจะบันทึก
- **การพิมพ์** — ตัวอย่างก่อนพิมพ์แบบสด พร้อมขนาดกระดาษ แนวกระดาษ มาตราส่วน (พอดี (ทั้งภาพ) / เต็มพื้นที่ (ครอบตัด) / ยืด (เต็มหน้า) / 100% / % กำหนดเอง / ความกว้างหรือความสูงเป็น mm) ระยะขอบ ตำแหน่ง พิมพ์สีหรือระดับสีเทา
- **เครื่องมือไฟล์** — บันทึก (การหมุน) บันทึกเป็น ส่งออก / บีบอัด (PNG, JPEG, BMP, TIFF, GIF) พร้อมปรับขนาดและประเมินขนาดไฟล์ คัดลอกรูปภาพหรือพาธไปยังคลิปบอร์ด เปลี่ยนชื่อ ย้ายไปถังรีไซเคิลหรือลบถาวร แสดงในโฟลเดอร์ ตั้งเป็นภาพพื้นหลังเดสก์ท็อป
- **รูปแบบไฟล์** — PNG, JPEG/JFIF, BMP/DIB, GIF, TIFF, DjVu, ICO, WMF/EMF, TGA, PCX, PSD (ภาพที่รวมเลเยอร์แล้ว), PBM/PGM/PPM/PNM, QOI
- **อินเทอร์เฟซ 30 ภาษา** — ตรวจหาภาษาของ Windows โดยอัตโนมัติ (หากไม่รองรับจะใช้ภาษาอังกฤษ) และเปลี่ยนได้จากเมนู; รองรับการจัดวางจากขวาไปซ้ายสำหรับภาษาอาหรับ ฮีบรู อูรดู และเปอร์เซีย
- **ธีม** — สว่าง มืด หรืออัตโนมัติ (ตามโหมดแอปของ Windows และสลับทันที)
- **เล็ก** — `Kadr.exe` ไฟล์เดียว ขนาดไม่ถึง 1 MB
- **Windows XP ขึ้นไป** — ทำงานได้ตั้งแต่ Windows XP SP3 (x86) จนถึง Windows 10/11

## ดาวน์โหลด / ติดตั้ง

1. ดาวน์โหลด `Kadr.exe` จาก[หน้า Releases](https://github.com/snakex21/kadr/releases) (มี `Kadr.exe` ที่พร้อมใช้งานเก็บไว้ที่รากของรีโพซิทอรีด้วย)
2. วางไฟล์ไว้ในโฟลเดอร์ใดก็ได้ที่คุณมีสิทธิ์เขียน (เช่น แฟลชไดรฟ์ USB) แล้วเปิดใช้งาน ไม่มีตัวติดตั้ง
3. สำหรับไฟล์ DjVu ให้เก็บโฟลเดอร์ `deps\djvu\` จากรีโพซิทอรีไว้ข้าง `Kadr.exe`

หากต้องการเปิดรูปภาพด้วยการดับเบิลคลิก ให้ใช้คำสั่ง *เปิดด้วย → เลือกแอปอื่น* ของ Windows กับรูปภาพ แล้วเลือก `Kadr.exe`

**ความต้องการของระบบ:** Windows XP SP3 x86 หรือใหม่กว่า (ใช้กับ Windows 10/11 ได้เช่นกัน) ไม่ต้องใช้อย่างอื่นอีก

> ตัวถอดรหัส DjVu คือ DjVuLibre 3.5.27 ซึ่งเป็นรุ่นเก่า — ควรเปิดเฉพาะไฟล์ DjVu ที่คุณเชื่อถือเท่านั้น (รายละเอียดใน `THIRD-PARTY.txt`)

## การใช้งาน

- **เปิด** รูปภาพด้วย **เปิด** (Ctrl+O) ลากไฟล์มาวางบนหน้าต่าง หรือส่งชื่อไฟล์ทางบรรทัดคำสั่ง: `Kadr.exe photo.jpg`
- **เลื่อนดู** ภาพในโฟลเดอร์ด้วย ← / → หรือปุ่มลูกศร ตัวนับจะแสดงตำแหน่ง (เช่น `1 / 3`) กดปุ่มลูกศรค้างไว้เพื่อเลื่อนดูอย่างรวดเร็ว
- **ซูม** ด้วยล้อเมาส์ (ซูม ณ ตำแหน่งเคอร์เซอร์) `+` / `−` **พอดี** (Home) **1:1** (`1`) หรือพิมพ์ค่าในช่องซูมแล้วกด Enter ลากภาพเพื่อเลื่อนดู
- **หมุน** ด้วย R / L การหมุนมีผลกับมุมมอง; **บันทึก** (Ctrl+S) จะเขียนการหมุนลงในไฟล์
- **เพิ่มเติม (…)** เปิดเมนูที่รวมคำสั่งไฟล์ทั้งหมด ตัวแก้ไข การพิมพ์ สไลด์โชว์ เต็มหน้าจอ วิธีใช้ *ตรวจหาการอัปเดต…* *ธีม* และ *ภาษา*
- **ตรวจหาการอัปเดต…** เพียงเปิดหน้ารุ่นเผยแพร่ของโปรเจกต์บน GitHub ในเว็บเบราว์เซอร์ของคุณ — ตัว Kadr เองไม่เคยเชื่อมต่ออินเทอร์เน็ต

## ตัวแก้ไข

เปิดตัวแก้ไขด้วย **แก้ไข** (Ctrl+E) การเปลี่ยนแปลงทั้งหมดจะเก็บไว้ในหน่วยความจำ ไฟล์ต้นฉบับจะไม่ถูกแตะต้องจนกว่าคุณจะบันทึก

- **ครอบตัด** — กรอบแบบสดที่มีจุดจับแปดจุด ลากกรอบหรือจุดจับ พิมพ์ค่า X / Y / ความกว้าง / ความสูงที่แน่นอนเป็นพิกเซล หรือเลือกสัดส่วนสำเร็จรูป (อิสระ, สี่เหลี่ยมจัตุรัส 1:1, 4:3, 3:4, 3:2 (4×6 แนวนอน), 2:3, 16:9, A4 แนวตั้ง, A4 แนวนอน) พื้นที่นอกกรอบจะมืดลง; **ครอบตัด** (Enter) จะตัดส่วนนั้นออก และ **ทั้งภาพ** จะรีเซ็ตกรอบ
- **การวาด** — ปากกา ปากกาเน้นข้อความแบบโปร่งแสง ยางลบ (ลบเฉพาะภาพวาดและข้อความ ไม่ลบตัวภาพถ่าย) เส้นตรง ลูกศร สี่เหลี่ยม และข้อความ พร้อมสีสิบสีและปรับขนาดเส้นได้
- **ภาพ** — เลิกทำ / ทำซ้ำ หมุน 90° ไปทางซ้ายหรือขวา สะท้อนแนวนอนหรือแนวตั้ง รีเซ็ตทั้งหมด
- **สีและแสง** — ความสว่าง ความเปรียบต่าง ความอิ่มสี และขาวดำ
- **เสร็จสิ้น** — *นำไปใช้* ส่งภาพที่แก้ไขแล้วกลับไปยังโปรแกรมดูภาพ, *บันทึกเป็น…* บันทึกสำเนาในชื่อใหม่, *พิมพ์…* ไปยังตัวอย่างก่อนพิมพ์ทันที, *ยกเลิก* (Esc) ละทิ้งการเปลี่ยนแปลง

## การพิมพ์

**พิมพ์** (Ctrl+P) เปิดตัวอย่างแผ่นกระดาษแบบสด เลือกเครื่องพิมพ์ กระดาษ (A3–A6, B4/B5, Letter, Legal, Executive, Tabloid, ขนาดภาพถ่าย 10×15, 13×18, 15×20, 20×25 cm, 4×6, 5×7, 8×10 in, กำหนดเอง หรือขนาดของเครื่องพิมพ์เอง) แนวกระดาษ และพิมพ์สีหรือระดับสีเทา แนวกระดาษจะปรับตามภาพโดยอัตโนมัติจนกว่าคุณจะเปลี่ยนเอง

โหมดมาตราส่วน:

| โหมด | ผลลัพธ์ |
|---|---|
| **พอดี (ทั้งภาพ)** | ภาพทั้งภาพอยู่ภายในระยะขอบ คงสัดส่วนไว้ อาจมีพื้นที่ว่างสีขาวเหลืออยู่สองด้าน |
| **เต็มพื้นที่ (ครอบตัด)** | ภาพครอบคลุมพื้นที่พิมพ์ทั้งหมด คงสัดส่วนไว้ และขอบที่ล้นออกไปจะถูกครอบตัด |
| **ยืด (เต็มหน้า)** | ภาพถูกยืดให้พอดีกับพื้นที่พิมพ์ทุกด้าน — ไม่มีแถบสีขาว แต่**ไม่**คงสัดส่วน |
| **100% · ขนาดจริง (96 DPI)** | หนึ่งพิกเซล = 1/96 นิ้ว |
| **เปอร์เซ็นต์กำหนดเอง** | 0.1–1000% เทียบกับ 96 DPI (100% = ขนาดข้างต้น) |
| **ความกว้าง (mm) / ความสูง (mm)** | ความกว้างหรือความสูงจริงที่แน่นอน อีกด้านหนึ่งจะเป็นไปตามสัดส่วน |

**ขั้นสูง ▸** เพิ่มขนาดกระดาษกำหนดเอง ระยะขอบ และตำแหน่งที่แน่นอนบนแผ่นกระดาษ (หรือลากภาพในตัวอย่าง; *จัดกึ่งกลาง* จะนำภาพกลับไปไว้ตรงกลาง) เส้นสีเทาแสดงขีดจำกัดทางฮาร์ดแวร์ของเครื่องพิมพ์ โหมดมาตราส่วนที่เลือกล่าสุดจะถูกจดจำไว้ใน `Kadr.ini`

## ธีม

**เพิ่มเติม (…) → ธีม** มีตัวเลือก **สว่าง** **มืด** และ **อัตโนมัติ** (ค่าเริ่มต้น)

- **อัตโนมัติ** จะตาม *โหมดแอป* ของ Windows (การตั้งค่า → การตั้งค่าส่วนบุคคล → สี, ค่า `AppsUseLightTheme`) และสลับทันทีเมื่อคุณเปลี่ยนใน Windows บนระบบที่ไม่มีการตั้งค่านี้ (Windows XP, Vista, 7, 8) อัตโนมัติจะหมายถึงสว่าง
- ธีมครอบคลุมหน้าต่างหลัก แถบเครื่องมือ ปุ่มและไอคอน ตัวแก้ไข ตัวอย่างก่อนพิมพ์ และกล่องโต้ตอบของ Kadr เอง ในโหมดมืด พื้นหลังของภาพจะเป็นสีเทาเข้ม และบน Windows 10/11 แถบชื่อเรื่องและเมนูป๊อปอัปก็จะเป็นสีมืดด้วย
- ส่วนประกอบเนทีฟของ Windows บางส่วนยังคงรูปลักษณ์ของระบบ: กล่องข้อความ (วิธีใช้ การยืนยัน) กล่องโต้ตอบระบบ เปิด / บันทึก / พิมพ์ และปุ่มเลื่อนของแถบเลื่อนปรับค่า

## การตั้งค่า (Kadr.ini)

การตั้งค่าทั้งหมดจะเก็บไว้ใน `Kadr.ini` ข้าง `Kadr.exe` หากโฟลเดอร์เป็นแบบอ่านอย่างเดียว Kadr จะแจ้งว่าไม่สามารถบันทึกการตั้งค่าได้

```ini
[General]
Language=en      ; pl, en, es, fr, de, pt, ru, uk, it, nl, cs, hu, ro, tr, el, ar, he, hi, bn, ur, zh, ja, ko, id, vi, th, fa, ta, te, mr
Theme=auto       ; auto, light or dark
[Print]
Scale=fit        ; fit, fill, stretch, actual, percent, width or height
```

เลือกภาษาได้จาก **เพิ่มเติม (…) → ภาษา** เช่นกัน การเปลี่ยนแปลงจะมีผลหลังจากเริ่ม Kadr ใหม่ ส่วนธีมจะมีผลทันที

ภาษาของอินเทอร์เฟซ: Polski, English, Español, Français, Deutsch, Português, Русский, Українська, Italiano, Nederlands, Čeština, Magyar, Română, Türkçe, Ελληνικά, العربية, עברית, हिन्दी, বাংলা, اردو, 中文, 日本語, 한국어, Bahasa Indonesia, Tiếng Việt, ไทย, فارسی, தமிழ், తెలుగు, मराठी.

## การสร้างจากซอร์สโค้ด

ความต้องการ: [Zig 0.11.0](https://ziglang.org/download/0.11.0/zig-windows-x86_64-0.11.0.zip) ที่แตกไฟล์ไว้ใน `tools\zig-windows-x86_64-0.11.0\` (ไฟล์บีบอัดไม่ได้อยู่ในรีโพซิทอรี; ค่า SHA-256 อยู่ใน `THIRD-PARTY.txt`)

```bat
build.cmd
```

ผลลัพธ์คือ `Kadr.exe` (เป้าหมาย `x86-windows.xp`, Pentium III, `ReleaseSmall`) ที่มีส่วนหัว PE เข้ากันได้กับ XP การสร้างไอคอนใหม่: `tools\build_icon.cmd` (Pillow + windres/objcopy)

Kadr ลิงก์เฉพาะไลบรารีที่มีอยู่ใน Windows XP ฟีเจอร์ที่ใหม่กว่า (แถบชื่อเรื่องสีมืด เมนูและตัวควบคุมสีมืด) จะโหลดขณะรันด้วย `LoadLibrary` / `GetProcAddress` และจะข้ามไปบนระบบที่เก่ากว่า

## การรันการทดสอบ

- ชุดทดสอบอยู่ในโฟลเดอร์ย่อยของ `tests\` (`editor-check`, `print-options`, `loader-check`, `image-check`, `codec-check`, `render-check`, `export-check`) แต่ละชุดเริ่มด้วย `check.cmd` ของตัวเอง ซึ่งจะบิลด์และรันชุดทดสอบ Zig `tests\editor-check\check.cmd` รันการทดสอบหน้าต่างหลัก (รวมถึงการทดสอบการตั้งค่าธีมและการเลือกธีม) การทดสอบตัวแก้ไข การตรวจสอบความครอบคลุมของภาษา และบิลด์ทดลองสำหรับ x86/XP; `tests\print-options\check.cmd` รันการทดสอบการพิมพ์และการจัดวาง
- การทดสอบหน่วยในแต่ละโมดูลรันได้ด้วย `zig test` เช่น `zig test src\toolbar.zig`, `src\navigation.zig`, `src\image.zig`, `src\zoom.zig`, `src\theme.zig` (ใช้เป้าหมายและแฟล็ก include เดียวกับใน `check.cmd`)
- สคริปต์ช่วยเหลือ Python 3: `python tests\i18n-check\run.py` (การเลือกภาษา), `python tests\locale_coverage.py` (ข้อความ UI ทั้งหมดอยู่ในแค็ตตาล็อกครบ 30 ภาษา), `python tests\audit_xp.py` (ตรวจสอบการนำเข้า/ส่วนหัวสำหรับ XP ของ `Kadr.exe`), `tests\measure_print.py`, `tests\tooltip_probe.py`, `tests\shot.py`
- `tests\generate_fixtures.py` สร้างภาพทดสอบ (ต้องใช้ Pillow) ใช้เฉพาะในการพัฒนาเท่านั้น `Kadr.exe` ไม่เคยใช้
