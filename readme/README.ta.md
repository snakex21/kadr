# Kadr

**Windows-க்கான வேகமான, மிகச் சிறிய, கையடக்கமான புகைப்படப் பார்வையாளர் மற்றும் திருத்தி — Windows XP முதல் Windows 11 வரை, 1 MB-க்கும் குறைவான ஒரே ஒரு `Kadr.exe` கோப்பில்.**

Kadr என்பது [Zig](https://ziglang.org/) மொழியில் எழுதப்பட்ட ஒரு சொந்த Win32/GDI+ பயன்பாடு. நிறுவி இல்லை, .NET இல்லை, Electron இல்லை, Node.js இல்லை: `Kadr.exe`-ஐ எங்கு வேண்டுமானாலும் நகலெடுத்து இயக்குங்கள். அமைப்புகள் நிரலுக்கு அருகிலுள்ள `Kadr.ini`-இல் சேமிக்கப்படும் (கையடக்கம் — பதிவகத்திலோ AppData-விலோ எதுவும் எழுதப்படுவதில்லை).

![Kadr முதன்மைச் சாளரம், ஒளி தீம்](../docs/screenshots/main-light.png)

## அம்சங்கள்

- **பார்வையாளர்** — புகைப்படங்களைத் திறத்தல், கோப்புறையில் உலாவுதல் (அம்புக்குறி விசைகள், முந்தைய/அடுத்த), படக்காட்சி, முழுத்திரை, மென்மையான பெரிதாக்கல் (பொருத்து, 1:1, சுட்டி இருக்கும் இடத்தில் சுட்டிச் சக்கரம், `125%`, `37,5%` அல்லது `200×` போன்ற தட்டச்சு செய்த மதிப்புகள்), படத்தை நகர்த்துதல், அசைவூட்ட GIF இயக்கம், பல பக்க TIFF மற்றும் DjVu, தானியங்கு EXIF திசையமைப்பு.
- **திருத்தி** — நேரடிச் சட்டகம் மற்றும் விகித முன்னமைவுகளுடன் செதுக்குதல் (கட்டற்றது, 1:1, 4:3, 3:4, 3:2, 2:3, 16:9, A4 நெடுக்கு/கிடை); பேனா, ஹைலைட்டர், அழிப்பான், கோடு, அம்பு, செவ்வகம் மற்றும் உரை; செயல்தவிர்/மீண்டும் செய்; சுழற்றுதல் மற்றும் புரட்டுதல்; ஒளிர்வு, மாறுபாடு, வண்ணச் செறிவு மற்றும் கருப்பு-வெள்ளை. நீங்கள் சேமிக்கும் வரை மாற்றங்கள் நினைவகத்திலேயே இருக்கும்.
- **அச்சிடுதல்** — தாள் அளவு, திசை, அளவுவிகிதம் (பொருத்து / நிரப்பு (செதுக்கலுடன்) / நீட்டு (முழுப் பக்கம்) / 100% / தனிப்பயன் % / mm-இல் அகலம் அல்லது உயரம்), ஓரங்கள், இடம், வண்ணம் அல்லது சாம்பல் நிறங்கள் ஆகியவற்றுடன் நேரடி அச்சு முன்னோட்டம்.
- **கோப்புக் கருவிகள்** — சேமி (சுழற்சி), வேறு பெயரில் சேமி, அளவு மாற்றம் மற்றும் அளவு மதிப்பீட்டுடன் ஏற்றுமதி / சுருக்கு (PNG, JPEG, BMP, TIFF, GIF), படத்தையோ பாதையையோ பிடிப்புப்பலகைக்கு நகலெடு, மறுபெயரிடு, மறுசுழற்சி தொட்டி அல்லது நிரந்தர நீக்கம், கோப்புறையில் காட்டு, பணிமேடைப் பின்புலமாக அமை.
- **வடிவங்கள்** — PNG, JPEG/JFIF, BMP/DIB, GIF, TIFF, DjVu, ICO, WMF/EMF, TGA, PCX, PSD (ஒன்றிணைந்த படம்), PBM/PGM/PPM/PNM, QOI.
- **30 இடைமுக மொழிகள்** — Windows மொழி தானாகக் கண்டறியப்படும் (இல்லையெனில் ஆங்கிலம் பயன்படும்), அதைப் பட்டியிலிருந்து மாற்றலாம்; அரபு, ஹீப்ரு, உருது மற்றும் பாரசீக மொழிகளுக்கு வலமிருந்து இடமான அமைப்பு.
- **தீம்கள்** — ஒளி, இருள் அல்லது தானியங்கு (Windows பயன்பாட்டுப் பயன்முறையைப் பின்பற்றி, உடனுக்குடன் மாறும்).
- **சிறியது** — 1 MB-க்கும் குறைவான ஒரே `Kadr.exe`.
- **Windows XP மற்றும் புதியவை** — Windows XP SP3 (x86) முதல் Windows 10/11 வரை இயங்கும்.

## பதிவிறக்கம் / நிறுவல்

1. [வெளியீடுகள் பக்கத்திலிருந்து](https://github.com/snakex21/kadr/releases) `Kadr.exe`-ஐப் பதிவிறக்குங்கள் (தயாரான ஒரு `Kadr.exe` களஞ்சியத்தின் மூலக் கோப்புறையிலும் வைக்கப்பட்டுள்ளது).
2. நீங்கள் எழுதக்கூடிய எந்தக் கோப்புறையிலும் (எடுத்துக்காட்டாக ஒரு USB நினைவகத்தில்) அதை வைத்து இயக்குங்கள். நிறுவி எதுவும் இல்லை.
3. DjVu கோப்புகளுக்கு, களஞ்சியத்திலுள்ள `deps\djvu\` கோப்புறையை `Kadr.exe`-க்கு அருகில் வைத்திருங்கள்.

இரட்டைக் கிளிக்கில் படங்களைத் திறக்க, Windows-இல் ஒரு படத்தின் மீது *இதன் மூலம் திற → வேறொரு பயன்பாட்டைத் தேர்வுசெய்* என்பதைப் பயன்படுத்தி `Kadr.exe`-ஐத் தேர்ந்தெடுங்கள்.

**தேவைகள்:** Windows XP SP3 x86 அல்லது புதியது (Windows 10/11-இலும் இயங்கும்). வேறு எதுவும் தேவையில்லை.

> DjVu குறிவிலக்கி பழைய DjVuLibre 3.5.27 ஆகும் — நீங்கள் நம்பும் DjVu கோப்புகளை மட்டுமே திறங்கள் (விவரங்கள் `THIRD-PARTY.txt`-இல்).

## பயன்பாடு

- **திற** பொத்தானை (Ctrl+O) அழுத்தியோ, கோப்பைச் சாளரத்தின் மீது இழுத்து விட்டோ, கட்டளை வரியில் கொடுத்தோ ஒரு படத்தைத் **திறக்கலாம்**: `Kadr.exe photo.jpg`.
- ← / → அல்லது அம்புப் பொத்தான்கள் மூலம் கோப்புறையில் **உலாவலாம்**; எண்ணி தற்போதைய நிலையைக் காட்டும் (எ.கா. `1 / 3`). வேகமாக உலாவ அம்புக்குறி விசையை அழுத்திப் பிடியுங்கள்.
- சுட்டிச் சக்கரம் (சுட்டி இருக்கும் இடத்தில் பெரிதாக்கும்), `+` / `−`, **பொருத்து** (Home), **1:1** (`1`) மூலம் **பெரிதாக்கலாம்**, அல்லது பெரிதாக்கல் புலத்தில் ஒரு மதிப்பைத் தட்டச்சு செய்து Enter அழுத்தலாம். படத்தை நகர்த்த அதை இழுங்கள்.
- R / L மூலம் **சுழற்றலாம்**. காட்சி மட்டுமே சுழலும்; **சேமி** (Ctrl+S) சுழற்சியைக் கோப்பில் எழுதும்.
- **மேலும் (…)** அனைத்துக் கோப்புச் செயல்பாடுகள், திருத்தி, அச்சிடுதல், படக்காட்சி, முழுத்திரை, உதவி, *புதுப்பிப்புகளைச் சரிபார்…*, *தீம்* மற்றும் *மொழி* ஆகியவை கொண்ட பட்டியைத் திறக்கும்.
- **புதுப்பிப்புகளைச் சரிபார்…** திட்டத்தின் GitHub வெளியீடுகள் பக்கத்தை உங்கள் இணைய உலாவியில் திறப்பது மட்டுமே செய்யும் — Kadr தானாக ஒருபோதும் இணையத்துடன் இணைவதில்லை.

## திருத்தி

**Edit** (திருத்து, Ctrl+E) மூலம் திருத்தியைத் திறக்கலாம். எல்லா மாற்றங்களும் நினைவகத்தில் வைக்கப்படும்; நீங்கள் சேமிக்கும் வரை மூலக் கோப்பு தொடப்படாது.

- **செதுக்கு** — எட்டுப் பிடிகளுடன் கூடிய நேரடிச் சட்டகம்; சட்டகத்தையோ அதன் பிடிகளையோ இழுக்கலாம், X / Y / அகலம் / உயரம் ஆகியவற்றைப் பிக்சல்களில் துல்லியமாகத் தட்டச்சு செய்யலாம், அல்லது ஒரு விகித முன்னமைவைத் தேர்ந்தெடுக்கலாம் (கட்டற்றது, சதுரம் 1:1, 4:3, 3:4, 3:2 (4×6 கிடை), 2:3, 16:9, A4 நெடுக்கு, A4 கிடை). சட்டகத்துக்கு வெளியே உள்ள பகுதி மங்கலாக்கப்படும்; **செதுக்கு** (Enter) அதை வெட்டி நீக்கும், **Whole photo** (முழுப் புகைப்படம்) சட்டகத்தை மீட்டமைக்கும்.
- **வரைதல்** — பேனா, ஒளிபுகும் ஹைலைட்டர், அழிப்பான் (வரைபடங்களையும் உரையையும் மட்டுமே அழிக்கும், புகைப்படத்தை ஒருபோதும் அழிக்காது), நேர்கோடு, அம்பு, செவ்வகம் மற்றும் உரை; பத்து வண்ணங்களும் சரிசெய்யக்கூடிய தடிமனும் உண்டு.
- **Image** (படம்) — செயல்தவிர் / மீண்டும் செய், இடப்புறம் அல்லது வலப்புறம் 90° சுழற்றுதல், கிடைமட்டமாக அல்லது செங்குத்தாகப் பிரதிபலித்தல், அனைத்தையும் மீட்டமைத்தல்.
- **Colour and light** (வண்ணமும் ஒளியும்) — ஒளிர்வு, மாறுபாடு, வண்ணச் செறிவு மற்றும் கருப்பு-வெள்ளை.
- **முடித்தல்** — *பயன்படுத்து* திருத்திய படத்தைப் பார்வையாளருக்குத் திருப்பி அனுப்பும், *Save as…* (வேறு பெயரில் சேமி) புதிய பெயரில் ஒரு நகலைச் சேமிக்கும், *Print…* (அச்சிடு) நேராக அச்சு முன்னோட்டத்துக்குச் செல்லும், *ரத்து* (Esc) மாற்றங்களைக் கைவிடும்.

## அச்சிடுதல்

**அச்சிடு** (Ctrl+P) தாளின் நேரடி முன்னோட்டத்தைத் திறக்கும். அச்சுப்பொறி, தாள் (A3–A6, B4/B5, Letter, Legal, Executive, Tabloid, புகைப்பட அளவுகள் 10×15, 13×18, 15×20, 20×25 cm, 4×6, 5×7, 8×10 in, தனிப்பயன் அல்லது அச்சுப்பொறியின் சொந்த அளவு), திசை, வண்ணம் அல்லது சாம்பல் நிறங்கள் ஆகியவற்றைத் தேர்ந்தெடுங்கள். நீங்கள் மாற்றும் வரை திசை தானாகவே படத்தைப் பின்பற்றும்.

அளவுவிகிதப் பயன்முறைகள்:

| பயன்முறை | என்ன செய்யும் |
|---|---|
| **பொருத்து** | முழுப் படமும் ஓரங்களுக்குள் பொருந்தும்; விகிதம் பேணப்படும், இரண்டு பக்கங்களில் வெற்று இடம் இருக்கலாம். |
| **நிரப்பு / செதுக்கு** | படம் முழு அச்சுப் பரப்பையும் மூடும்; விகிதம் பேணப்படும், வெளியே நீளும் விளிம்புகள் செதுக்கப்படும். |
| **Stretch (whole page)** (நீட்டு: முழுப் பக்கம்) | படம் அச்சுப் பரப்புக்குத் துல்லியமாக நீட்டப்படும் — வெள்ளைப் பட்டைகள் இருக்காது, ஆனால் விகிதம் **பேணப்படாது**. |
| **100% · உண்மை அளவு (96 DPI)** | ஒரு பிக்சல் = 1/96 அங்குலம். |
| **தனிப்பயன் சதவீதம்** | 96 DPI-ஐப் பொறுத்து 0.1–1000 % (100% = மேலே உள்ள அளவு). |
| **அகலம் / உயரம் (mm)** | துல்லியமான இயற்பியல் அகலம் அல்லது உயரம்; மறுபக்கம் விகிதத்தின்படி அமையும். |

**மேம்பட்டவை ▸** தனிப்பயன் தாள் அளவு, ஓரங்கள், தாளில் துல்லியமான இடம் ஆகியவற்றைச் சேர்க்கும் (அல்லது முன்னோட்டத்தில் படத்தை இழுங்கள்; *மையம்* அதை மீண்டும் நடுவில் வைக்கும்). சாம்பல் கோடு அச்சுப்பொறியின் வன்பொருள் வரம்பைக் காட்டும். கடைசியாகத் தேர்ந்தெடுத்த அளவுவிகிதப் பயன்முறை `Kadr.ini`-இல் நினைவில் வைக்கப்படும்.

## தீம்கள்

**மேலும் (…) → தீம்** **ஒளி**, **இருள்** மற்றும் **தானியங்கு** (இயல்புநிலை) ஆகியவற்றை வழங்கும்.

- **தானியங்கு** Windows *பயன்பாட்டுப் பயன்முறையைப்* (அமைப்புகள் → தனிப்பயனாக்கம் → வண்ணங்கள், `AppsUseLightTheme` மதிப்பு) பின்பற்றும்; Windows-இல் அதை மாற்றும்போது உடனுக்குடன் மாறும். அந்த அமைப்பு இல்லாத கணினிகளில் (Windows XP, Vista, 7, 8) தானியங்கு என்பது ஒளி என்றே பொருள்படும்.
- முதன்மைச் சாளரம், கருவிப்பட்டை, பொத்தான்கள் மற்றும் படவுருக்கள், திருத்தி, அச்சு முன்னோட்டம், Kadr-இன் சொந்த உரையாடல் பெட்டிகள் ஆகிய அனைத்துக்கும் தீம் பொருந்தும். இருள் பயன்முறையில் படத்தின் பின்னணி அடர் சாம்பல் நிறமாக இருக்கும்; Windows 10/11-இல் தலைப்புப் பட்டைகளும் மேல்தோன்றும் பட்டிகளும் இருளாக இருக்கும்.
- சில சொந்த Windows பகுதிகள் கணினியின் தோற்றத்தையே வைத்திருக்கும்: செய்திப் பெட்டிகள் (உதவி, உறுதிப்படுத்தல்கள்), திற / சேமி / அச்சிடு கணினி உரையாடல் பெட்டிகள் மற்றும் நழுவியின் குமிழ்கள்.

## அமைப்புகள் (Kadr.ini)

எல்லா அமைப்புகளும் `Kadr.exe`-க்கு அருகிலுள்ள `Kadr.ini`-இல் சேமிக்கப்படும். கோப்புறை படிக்க மட்டுமேயானதாக இருந்தால், அமைப்புகளைச் சேமிக்க முடியாது என்று Kadr தெரிவிக்கும்.

```ini
[General]
Language=en      ; pl, en, es, fr, de, pt, ru, uk, it, nl, cs, hu, ro, tr, el, ar, he, hi, bn, ur, zh, ja, ko, id, vi, th, fa, ta, te, mr
Theme=auto       ; auto, light or dark
[Print]
Scale=fit        ; fit, fill, stretch, actual, percent, width or height
```

மொழியை **மேலும் (…) → மொழி** என்பதிலும் தேர்ந்தெடுக்கலாம்; Kadr-ஐ மறுதொடக்கம் செய்த பிறகு மாற்றம் நடைமுறைக்கு வரும். தீம் உடனடியாகப் பொருந்தும்.

இடைமுக மொழிகள்: Polski, English, Español, Français, Deutsch, Português, Русский, Українська, Italiano, Nederlands, Čeština, Magyar, Română, Türkçe, Ελληνικά, العربية, עברית, हिन्दी, বাংলা, اردو, 中文, 日本語, 한국어, Bahasa Indonesia, Tiếng Việt, ไทย, فارسی, தமிழ், తెలుగు, मराठी.

## மூலக் குறியீட்டிலிருந்து உருவாக்குதல்

தேவைகள்: `tools\zig-windows-x86_64-0.11.0\`-இல் பிரித்தெடுக்கப்பட்ட [Zig 0.11.0](https://ziglang.org/download/0.11.0/zig-windows-x86_64-0.11.0.zip) (அந்தக் காப்பகம் களஞ்சியத்தின் பகுதி அல்ல; அதன் SHA-256 `THIRD-PARTY.txt`-இல் உள்ளது).

```bat
build.cmd
```

விளைவு XP-இணக்கமான PE தலைப்புடன் கூடிய `Kadr.exe` (இலக்கு `x86-windows.xp`, Pentium III, `ReleaseSmall`). படவுருவை மீண்டும் உருவாக்க: `tools\build_icon.cmd` (Pillow + windres/objcopy).

Windows XP-இல் உள்ள நூலகங்களுடன் மட்டுமே Kadr இணைக்கப்படுகிறது. புதிய அம்சங்கள் (இருள் தலைப்புப் பட்டைகள், இருள் பட்டிகள் மற்றும் கட்டுப்பாடுகள்) இயக்க நேரத்தில் `LoadLibrary` / `GetProcAddress` மூலம் ஏற்றப்படுகின்றன; பழைய கணினிகளில் அவை தவிர்க்கப்படுகின்றன.

## சோதனைகளை இயக்குதல்

- சோதனைத் தொகுப்புகள் `tests\` துணைக் கோப்புறைகளில் உள்ளன (`editor-check`, `print-options`, `loader-check`, `image-check`, `codec-check`, `render-check`, `export-check`); ஒவ்வொன்றும் அதன் `check.cmd` மூலம் தொடங்கப்படுகிறது, அது Zig சோதனை நிரல்களை உருவாக்கி இயக்கும். `tests\editor-check\check.cmd` முதன்மைச் சாளரச் சோதனைகள் (தீம் அமைப்பு மற்றும் தீம் தீர்மானச் சோதனைகள் உட்பட), திருத்திச் சோதனைகள், மொழி உள்ளடக்கச் சரிபார்ப்பு மற்றும் ஒரு x86/XP வேட்பு உருவாக்கம் ஆகியவற்றை இயக்கும்; `tests\print-options\check.cmd` அச்சிடுதல் மற்றும் தளவமைப்புச் சோதனைகளை இயக்கும்.
- தனித்தனி தொகுதிகளின் அலகுச் சோதனைகளை `zig test` மூலம் இயக்கலாம், எ.கா. `zig test src\toolbar.zig`, `src\navigation.zig`, `src\image.zig`, `src\zoom.zig`, `src\theme.zig` (`check.cmd`-இல் உள்ள அதே இலக்கு மற்றும் include கொடிகளுடன்).
- Python 3 உதவிக் கருவிகள்: `python tests\i18n-check\run.py` (மொழித் தேர்வு), `python tests\locale_coverage.py` (எல்லா இடைமுகச் சரங்களும் 30 மொழிகளுக்கான பட்டியலில் உள்ளன), `python tests\audit_xp.py` (`Kadr.exe`-இன் XP இறக்குமதி/தலைப்புத் தணிக்கை), `tests\measure_print.py`, `tests\tooltip_probe.py`, `tests\shot.py`.
- `tests\generate_fixtures.py` சோதனைப் படங்களை உருவாக்கும் (Pillow தேவை); இது மேம்பாட்டுக்கு மட்டுமே பயன்படுகிறது, `Kadr.exe` ஒருபோதும் இதைப் பயன்படுத்துவதில்லை.
