# Kadr

**Windows కోసం వేగవంతమైన, అతి చిన్న, పోర్టబుల్ ఫోటో వ్యూయర్ మరియు ఎడిటర్ — Windows XP నుండి Windows 11 వరకు, 1 MB కంటే చిన్నదైన ఒకే `Kadr.exe` ఫైల్‌లో.**

Kadr అనేది [Zig](https://ziglang.org/)లో రాసిన స్థానిక (native) Win32/GDI+ అప్లికేషన్. ఇన్‌స్టాలర్ లేదు, .NET లేదు, Electron లేదు, Node.js లేదు: `Kadr.exe`ని ఎక్కడికైనా కాపీ చేసి నడపండి. సెట్టింగ్‌లు ప్రోగ్రామ్ పక్కనే ఉండే `Kadr.ini`లో భద్రపరచబడతాయి (పోర్టబుల్ — రిజిస్ట్రీలో గానీ AppDataలో గానీ ఏమీ రాయబడదు).

![Kadr ప్రధాన విండో, లైట్ థీమ్](../docs/screenshots/main-light.png)

## విశేషాలు

- **వ్యూయర్** — ఫోటోలు తెరవడం, ఫోల్డర్‌లో ముందుకు వెనక్కు వెళ్లడం (బాణం కీలు, మునుపటి/తదుపరి), స్లయిడ్ షో, పూర్తి తెర, మృదువైన జూమ్ (సరిపరచు, 1:1, కర్సర్ ఉన్న చోట మౌస్ వీల్, `125%`, `37,5%` లేదా `200×` వంటి టైప్ చేసిన విలువలు), చిత్రాన్ని జరపడం, యానిమేటెడ్ GIF ప్లేబ్యాక్, బహుళ పేజీల TIFF మరియు DjVu, EXIF ఆధారంగా స్వయంచాలక దిశ.
- **ఎడిటర్** — లైవ్ ఫ్రేమ్ మరియు సిద్ధంగా ఉన్న నిష్పత్తులతో (ఏదైనా, 1:1, 4:3, 3:4, 3:2, 2:3, 16:9, A4 నిలువు/అడ్డం) కత్తిరింపు; పెన్, హైలైటర్, ఎరేజర్, గీత, బాణం, దీర్ఘచతురస్రం మరియు టెక్స్ట్; అన్‌డూ/రీడూ; తిప్పడం మరియు ప్రతిబింబించడం; ప్రకాశం, కాంట్రాస్ట్, సంతృప్తత మరియు నలుపు-తెలుపు. మీరు సేవ్ చేసే వరకు మార్పులు మెమరీలోనే ఉంటాయి.
- **ముద్రణ** — కాగితం పరిమాణం, దిశ, స్కేలు (సరిపరచు / నింపు (కత్తిరించి) / సాగదీయి (పూర్తి పేజీ) / 100% / సొంత % / mmలో వెడల్పు లేదా ఎత్తు), అంచులు, స్థానం, రంగు లేదా బూడిద రంగులతో లైవ్ ముద్రణ ప్రివ్యూ.
- **ఫైల్ సాధనాలు** — సేవ్ (తిప్పిన స్థితి), ఇలా సేవ్ చేయి, ఎగుమతి / కుదింపు (PNG, JPEG, BMP, TIFF, GIF) పరిమాణం మార్పు మరియు పరిమాణ అంచనాతో, చిత్రాన్ని లేదా పాత్‌ను క్లిప్‌బోర్డ్‌కు కాపీ చేయడం, పేరు మార్చడం, రీసైకిల్ బిన్‌కు పంపడం లేదా శాశ్వతంగా తొలగించడం, ఫోల్డర్‌లో చూపడం, డెస్క్‌టాప్ వాల్‌పేపర్‌గా పెట్టడం.
- **ఫార్మాట్‌లు** — PNG, JPEG/JFIF, BMP/DIB, GIF, TIFF, DjVu, ICO, WMF/EMF, TGA, PCX, PSD (విలీనమైన చిత్రం), PBM/PGM/PPM/PNM, QOI.
- **30 ఇంటర్‌ఫేస్ భాషలు** — Windows భాష స్వయంచాలకంగా గుర్తించబడుతుంది (లేకపోతే ఇంగ్లీష్), దాన్ని మెనూ నుండి మార్చవచ్చు; అరబిక్, హీబ్రూ, ఉర్దూ మరియు పర్షియన్ కోసం కుడి నుండి ఎడమకు లేఅవుట్.
- **థీములు** — లైట్, డార్క్ లేదా ఆటోమేటిక్ (Windows యాప్ మోడ్‌ను అనుసరిస్తుంది, వెంటనే మారుతుంది).
- **చిన్నది** — 1 MB కంటే చిన్నదైన ఒకే `Kadr.exe`.
- **Windows XP మరియు ఆ తర్వాతివి** — Windows XP SP3 (x86) నుండి Windows 10/11 వరకు పనిచేస్తుంది.

## డౌన్లోడ్ / ఇన్స్టాలేషన్

1. `Kadr.exe`ని [రిలీజ్‌ల పేజీ](https://github.com/snakex21/kadr/releases) నుండి డౌన్‌లోడ్ చేయండి (సిద్ధంగా ఉన్న ఒక `Kadr.exe` రిపాజిటరీ రూట్‌లో కూడా ఉంటుంది).
2. మీరు రాయగలిగే ఏ ఫోల్డర్‌లోనైనా (ఉదాహరణకు USB స్టిక్) దాన్ని ఉంచి నడపండి. ఇన్‌స్టాలర్ లేదు.
3. DjVu ఫైల్‌ల కోసం, రిపాజిటరీలోని `deps\djvu\` ఫోల్డర్‌ను `Kadr.exe` పక్కనే ఉంచండి.

డబుల్-క్లిక్‌తో చిత్రాలను తెరవడానికి, ఏదైనా చిత్రంపై Windows *దీనితో తెరువు → మరొక యాప్‌ను ఎంచుకోండి* ఉపయోగించి `Kadr.exe`ని ఎంచుకోండి.

**అవసరాలు:** Windows XP SP3 x86 లేదా కొత్తది (Windows 10/11 కూడా పనిచేస్తాయి). ఇంకేమీ అవసరం లేదు.

> DjVu డీకోడర్ పాత DjVuLibre 3.5.27 — మీరు నమ్మే DjVu ఫైల్‌లను మాత్రమే తెరవండి (వివరాలు `THIRD-PARTY.txt`లో).

## వినియోగం

- **తెరవడం**: **తెరువు** (Ctrl+O)తో, ఫైల్‌ను విండోపైకి లాగడం ద్వారా, లేదా కమాండ్ లైన్‌లో ఇవ్వడం ద్వారా చిత్రాన్ని తెరవండి: `Kadr.exe photo.jpg`.
- **బ్రౌజ్ చేయడం**: ← / → లేదా బాణం బటన్‌లతో ఫోల్డర్‌లో కదలండి; కౌంటర్ స్థానాన్ని చూపుతుంది (ఉదా. `1 / 3`). వేగంగా కదలడానికి బాణం కీని నొక్కి పట్టుకోండి.
- **జూమ్**: మౌస్ వీల్ (కర్సర్ ఉన్న చోట జూమ్ అవుతుంది), `+` / `−`, **సరిపరచు** (Home), **1:1** (`1`) ఉపయోగించండి, లేదా జూమ్ ఫీల్డ్‌లో విలువను టైప్ చేసి Enter నొక్కండి. చిత్రాన్ని జరపడానికి దాన్ని లాగండి.
- **తిప్పడం**: R / Lతో. తిరిగేది వీక్షణ మాత్రమే; **సేవ్ చేయి** (Ctrl+S) తిప్పిన స్థితిని ఫైల్‌లో రాస్తుంది.
- **మరిన్ని (…)** అన్ని ఫైల్ ఆపరేషన్‌లు, ఎడిటర్, ముద్రణ, స్లయిడ్ షో, పూర్తి తెర, సహాయం, *నవీకరణల కోసం తనిఖీ…*, *థీమ్* మరియు *భాష* ఉన్న మెనూను తెరుస్తుంది.
- **నవీకరణల కోసం తనిఖీ…** ప్రాజెక్ట్ GitHub రిలీజ్‌ల పేజీని మీ వెబ్ బ్రౌజర్‌లో తెరుస్తుంది అంతే — Kadr స్వయంగా ఎప్పుడూ ఇంటర్నెట్‌కు కనెక్ట్ అవ్వదు.

## ఎడిటర్

ఎడిటర్‌ను **Edit** ("సవరించు", Ctrl+E)తో తెరవండి. అన్ని మార్పులు మెమరీలో ఉంచబడతాయి; మీరు సేవ్ చేసే వరకు అసలు ఫైల్ మారదు.

- **కత్తిరింపు** — ఎనిమిది హ్యాండిల్‌లతో లైవ్ ఫ్రేమ్; ఫ్రేమ్‌ను లేదా దాని హ్యాండిల్‌లను లాగండి, పిక్సెల్‌లలో ఖచ్చితమైన X / Y / వెడల్పు / ఎత్తు టైప్ చేయండి, లేదా సిద్ధంగా ఉన్న నిష్పత్తిని ఎంచుకోండి (ఏదైనా, చతురస్రం 1:1, 4:3, 3:4, 3:2 (4×6 అడ్డం), 2:3, 16:9, A4 నిలువు, A4 అడ్డం). ఫ్రేమ్ బయటి ప్రాంతం మసకబారుతుంది; **కత్తిరించు** (Enter) దాన్ని కత్తిరిస్తుంది, **Whole photo** (మొత్తం ఫోటో) ఫ్రేమ్‌ను రీసెట్ చేస్తుంది.
- **గీయడం** — పెన్, పాక్షిక పారదర్శక హైలైటర్, ఎరేజర్ (గీతలు మరియు టెక్స్ట్‌ను మాత్రమే చెరుపుతుంది, ఫోటోను ఎప్పుడూ కాదు), సరళ రేఖ, బాణం, దీర్ఘచతురస్రం మరియు టెక్స్ట్, పది రంగులు మరియు సర్దుబాటు చేయగల మందంతో.
- **చిత్రం** — అన్‌డూ / రీడూ, ఎడమకు లేదా కుడికి 90° తిప్పడం, అడ్డంగా లేదా నిలువుగా ప్రతిబింబించడం, అన్నీ రీసెట్ చేయడం.
- **రంగు మరియు వెలుతురు** — ప్రకాశం, కాంట్రాస్ట్, సంతృప్తత మరియు నలుపు-తెలుపు.
- **ముగించడం** — *వర్తింపజేయి* సవరించిన చిత్రాన్ని వ్యూయర్‌కు తిరిగి పంపుతుంది, *Save as…* కొత్త పేరుతో కాపీని సేవ్ చేస్తుంది, *Print…* నేరుగా ముద్రణ ప్రివ్యూకు వెళ్తుంది, *రద్దు* (Esc) మార్పులను వదిలేస్తుంది.

## ముద్రణ

**ముద్రించు** (Ctrl+P) షీట్ యొక్క లైవ్ ప్రివ్యూను తెరుస్తుంది. ప్రింటర్, కాగితం (A3–A6, B4/B5, Letter, Legal, Executive, Tabloid, ఫోటో పరిమాణాలు 10×15, 13×18, 15×20, 20×25 cm, 4×6, 5×7, 8×10 in, సొంత పరిమాణం లేదా ప్రింటర్ స్వంతది), దిశ మరియు రంగు లేదా బూడిద రంగులను ఎంచుకోండి. మీరు మార్చే వరకు దిశ స్వయంచాలకంగా చిత్రాన్ని అనుసరిస్తుంది.

స్కేలు మోడ్‌లు:

| మోడ్ | ఏం చేస్తుంది |
|---|---|
| **సరిపరచు** | మొత్తం చిత్రం అంచుల లోపల సరిపోతుంది; నిష్పత్తి నిలుస్తుంది, రెండు వైపులా తెల్లని ఖాళీ మిగలవచ్చు. |
| **నింపు / కత్తిరించు** | చిత్రం మొత్తం ముద్రణ ప్రాంతాన్ని కప్పుతుంది; నిష్పత్తి నిలుస్తుంది, బయటకు వచ్చిన అంచులు కత్తిరించబడతాయి. |
| **Stretch (whole page)** (పూర్తి పేజీకి సాగదీయి) | చిత్రం సరిగ్గా ముద్రణ ప్రాంతానికి సాగదీయబడుతుంది — తెల్లని పట్టీలు ఉండవు, కానీ నిష్పత్తి **నిలవదు**. |
| **100% · అసలు పరిమాణం (96 DPI)** | ఒక పిక్సెల్ = 1/96 అంగుళం. |
| **సొంత శాతం** | 96 DPIకి సాపేక్షంగా 0.1–1000 % (100% = పై పరిమాణం). |
| **వెడల్పు (mm)** / **ఎత్తు (mm)** | ఖచ్చితమైన భౌతిక వెడల్పు లేదా ఎత్తు; మరో వైపు నిష్పత్తిని అనుసరిస్తుంది. |

**అధునాతన ▸** సొంత కాగితం పరిమాణం, అంచులు మరియు షీట్‌పై ఖచ్చితమైన స్థానాన్ని జోడిస్తుంది (లేదా ప్రివ్యూలో చిత్రాన్ని లాగండి; *మధ్యలో* దాన్ని మళ్లీ మధ్యకు తెస్తుంది). బూడిద గీత ప్రింటర్ హార్డ్‌వేర్ పరిమితిని చూపుతుంది. చివరిగా ఎంచుకున్న స్కేలు మోడ్ `Kadr.ini`లో గుర్తుంచుకోబడుతుంది.

## థీములు

**మరిన్ని (…) → థీమ్** **లైట్**, **డార్క్** మరియు **ఆటోమేటిక్** (డిఫాల్ట్) ఎంపికలను ఇస్తుంది.

- **ఆటోమేటిక్** Windows *యాప్ మోడ్‌ను* అనుసరిస్తుంది (సెట్టింగ్‌లు → వ్యక్తిగతీకరణ → రంగులు, `AppsUseLightTheme` విలువ) మరియు మీరు Windowsలో దాన్ని మార్చినప్పుడు వెంటనే మారుతుంది. ఆ సెట్టింగ్ లేని సిస్టమ్‌లలో (Windows XP, Vista, 7, 8) ఆటోమేటిక్ అంటే లైట్.
- థీమ్ ప్రధాన విండో, టూల్‌బార్, బటన్‌లు మరియు ఐకాన్‌లు, ఎడిటర్, ముద్రణ ప్రివ్యూ మరియు Kadr స్వంత డైలాగ్‌లకు వర్తిస్తుంది. డార్క్ మోడ్‌లో చిత్రం నేపథ్యం ముదురు బూడిద రంగులో ఉంటుంది, Windows 10/11లో టైటిల్ బార్‌లు మరియు పాప్అప్ మెనూలు కూడా ముదురుగా ఉంటాయి.
- కొన్ని స్థానిక Windows భాగాలు సిస్టమ్ రూపాన్నే ఉంచుకుంటాయి: సందేశ పెట్టెలు (సహాయం, నిర్ధారణలు), తెరువు / సేవ్ / ముద్రణ సిస్టమ్ డైలాగ్‌లు మరియు స్లైడర్ పిడులు.

## సెట్టింగులు (Kadr.ini)

అన్ని సెట్టింగ్‌లు `Kadr.exe` పక్కనే ఉండే `Kadr.ini`లో భద్రపరచబడతాయి. ఫోల్డర్ చదవడానికి మాత్రమే అయితే, సెట్టింగ్‌లను సేవ్ చేయలేమని Kadr మీకు తెలియజేస్తుంది.

```ini
[General]
Language=en      ; pl, en, es, fr, de, pt, ru, uk, it, nl, cs, hu, ro, tr, el, ar, he, hi, bn, ur, zh, ja, ko, id, vi, th, fa, ta, te, mr
Theme=auto       ; auto, light or dark
[Print]
Scale=fit        ; fit, fill, stretch, actual, percent, width or height
```

భాషను **మరిన్ని (…) → భాష** నుండి కూడా ఎంచుకోవచ్చు; Kadrను మళ్లీ ప్రారంభించిన తర్వాత మార్పు అమలవుతుంది. థీమ్ వెంటనే వర్తిస్తుంది.

ఇంటర్‌ఫేస్ భాషలు: Polski, English, Español, Français, Deutsch, Português, Русский, Українська, Italiano, Nederlands, Čeština, Magyar, Română, Türkçe, Ελληνικά, العربية, עברית, हिन्दी, বাংলা, اردو, 中文, 日本語, 한국어, Bahasa Indonesia, Tiếng Việt, ไทย, فارسی, தமிழ், తెలుగు, मराठी.
