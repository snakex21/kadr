# Kadr

**Быстрый, крошечный и портативный просмотрщик и редактор фотографий для Windows — от Windows XP до Windows 11, в одном файле `Kadr.exe` размером меньше 1 MB.**

Kadr — нативное приложение Win32/GDI+, написанное на [Zig](https://ziglang.org/). Без установщика, без .NET, без Electron, без Node.js: скопируйте `Kadr.exe` куда угодно и запустите. Настройки хранятся в `Kadr.ini` рядом с программой (портативно — ничего не записывается ни в реестр, ни в AppData).

## Возможности

- **Просмотр** — открытие фотографий, листание папки (клавиши со стрелками, предыдущее/следующее), слайд-шоу, полноэкранный режим, плавное масштабирование (вписать, 1:1, колесо мыши относительно курсора, введённые значения вроде `125%`, `37,5%` или `200×`), прокрутка перетаскиванием, воспроизведение анимированных GIF, многостраничные TIFF и DjVu, автоматический поворот по EXIF.
- **Редактор** — обрезка с живой рамкой и готовыми пропорциями (свободно, 1:1, 4:3, 3:4, 3:2, 2:3, 16:9, A4 книжная/альбомная); перо, маркер, ластик, линия, стрелка, прямоугольник и текст; отмена/повтор; поворот и отражение; яркость, контрастность, насыщенность и чёрно-белый режим. Изменения хранятся в памяти, пока вы не сохраните файл.
- **Печать** — живой предварительный просмотр с выбором размера бумаги, ориентации, масштаба (Вписать (всё изображение) / Заполнить (обрезать) / Растянуть (вся страница) / 100% / свой % / ширина или высота в mm), полей, положения, цветной печати или оттенков серого.
- **Работа с файлами** — сохранение (поворота), сохранение как, экспорт / сжатие (PNG, JPEG, BMP, TIFF, GIF) с изменением размера и оценкой размера файла, копирование изображения или пути в буфер обмена, переименование, удаление в корзину или навсегда, показ в папке, установка в качестве фона рабочего стола.
- **Форматы** — PNG, JPEG/JFIF, BMP/DIB, GIF, TIFF, DjVu, ICO, WMF/EMF, TGA, PCX, PSD (сведённое изображение), PBM/PGM/PPM/PNM, QOI.
- **30 языков интерфейса** — язык Windows определяется автоматически (иначе используется английский), его можно сменить в меню; для арабского, иврита, урду и персидского интерфейс отображается справа налево.
- **Темы** — светлая, тёмная или автоматическая (следует режиму приложений Windows и переключается на лету).
- **Маленький размер** — один `Kadr.exe` меньше 1 MB.
- **Windows XP и новее** — работает от Windows XP SP3 (x86) до Windows 10/11.

## Скачивание / установка

1. Скачайте `Kadr.exe` со [страницы релизов](https://github.com/snakex21/kadr/releases) (готовый `Kadr.exe` также лежит в корне репозитория).
2. Поместите его в любую папку, доступную для записи (например, на USB-флешку), и запустите. Установщика нет.
3. Для файлов DjVu держите папку `deps\djvu\` из репозитория рядом с `Kadr.exe`.

Чтобы открывать изображения двойным щелчком, выберите в Windows для изображения *Открыть с помощью → Выбрать другое приложение* и укажите `Kadr.exe`.

**Требования:** Windows XP SP3 x86 или новее (Windows 10/11 тоже подходят). Больше ничего.

> Декодер DjVu — это старая версия DjVuLibre 3.5.27, поэтому открывайте только те файлы DjVu, которым доверяете (подробности в `THIRD-PARTY.txt`).

## Использование

- **Открывайте** изображение кнопкой **Открыть** (Ctrl+O), перетаскиванием файла в окно или через командную строку: `Kadr.exe photo.jpg`.
- **Листайте** папку клавишами ← / → или кнопками со стрелками; счётчик показывает позицию (например, `1 / 3`). Удерживайте клавишу со стрелкой, чтобы листать быстро.
- **Масштабируйте** колесом мыши (относительно курсора), клавишами `+` / `−`, кнопками **Вписать** (Home), **1:1** (`1`) или введите значение в поле масштаба и нажмите Enter. Перетаскивайте изображение, чтобы сдвинуть его.
- **Поворачивайте** клавишами R / L. Поворачивается вид; **Сохранить** (Ctrl+S) записывает поворот в файл.
- **Ещё (…)** открывает меню со всеми операциями над файлом, редактором, печатью, слайд-шоу, полноэкранным режимом, справкой, пунктами *Проверить обновления…*, *Тема* и *Язык*.
- **Проверить обновления…** лишь открывает страницу релизов проекта на GitHub в вашем браузере — сам Kadr никогда не подключается к интернету.

## Редактор

Редактор открывается кнопкой **Правка** (Ctrl+E). Все изменения хранятся в памяти; исходный файл не меняется, пока вы его не сохраните.

- **Обрезка** — живая рамка с восемью маркерами; перетаскивайте рамку или маркеры, введите точные X / Y / ширину / высоту в пикселях или выберите готовую пропорцию (свободно, квадрат 1:1, 4:3, 3:4, 3:2 (4×6 альбомная), 2:3, 16:9, A4 книжная, A4 альбомная). Область за рамкой затемняется; **Обрезать** (Enter) отрезает её, а **Всё фото** сбрасывает рамку.
- **Рисование** — перо, полупрозрачный маркер, ластик (стирает только рисунки и текст, но никогда само фото), прямая линия, стрелка, прямоугольник и текст; десять цветов и настраиваемая толщина.
- **Изображение** — отмена / повтор, поворот на 90° влево или вправо, зеркальное отражение по горизонтали или вертикали, сброс всех изменений.
- **Цвет и свет** — яркость, контрастность, насыщенность и чёрно-белый режим.
- **Завершение** — *Применить* возвращает отредактированное изображение в просмотрщик, *Сохранить как…* сохраняет копию под новым именем, *Печать…* сразу переходит к предварительному просмотру печати, *Отмена* (Esc) отбрасывает изменения.

## Печать

**Печать** (Ctrl+P) открывает живой предварительный просмотр листа. Выберите принтер, бумагу (A3–A6, B4/B5, Letter, Legal, Executive, Tabloid, фотоформаты 10×15, 13×18, 15×20, 20×25 cm, 4×6, 5×7, 8×10 in, свой размер или формат принтера), ориентацию и цветную печать или оттенки серого. Ориентация автоматически подстраивается под изображение, пока вы не измените её вручную.

Режимы масштаба:

| Режим | Что делает |
|---|---|
| **Вписать (всё изображение)** | Всё изображение помещается внутри полей; пропорции сохраняются, по двум сторонам могут остаться белые поля. |
| **Заполнить (обрезать)** | Изображение покрывает всю область печати; пропорции сохраняются, выступающие края обрезаются. |
| **Растянуть (вся страница)** | Изображение растягивается точно по области печати — без белых полос, но пропорции **не** сохраняются. |
| **100% · Исходный размер (96 DPI)** | Один пиксель = 1/96 дюйма. |
| **Свой процент** | 0.1–1000 % относительно 96 DPI (100% = размер из строки выше). |
| **Ширина / Высота (mm)** | Точная физическая ширина или высота; другая сторона вычисляется по пропорциям. |

**Дополнительно ▸** добавляет свой размер бумаги, поля и точное положение на листе (или перетащите изображение в окне просмотра; *По центру* возвращает его в середину). Серая линия показывает аппаратную границу печати принтера. Последний выбранный режим масштаба запоминается в `Kadr.ini`.

## Темы

**Ещё (…) → Тема** предлагает **Светлая**, **Тёмная** и **Автоматически** (по умолчанию).

- **Автоматически** следует *режиму приложений* Windows (Параметры → Персонализация → Цвета, значение `AppsUseLightTheme`) и переключается на лету, когда вы меняете его в Windows. В системах без этой настройки (Windows XP, Vista, 7, 8) «Автоматически» означает «Светлая».
- Тема охватывает главное окно, панель инструментов, кнопки и значки, редактор, предварительный просмотр печати и собственные диалоговые окна Kadr. В тёмном режиме фон изображения тёмно-серый, а в Windows 10/11 тёмными становятся также заголовки окон и всплывающие меню.
- Некоторые стандартные элементы Windows сохраняют системный вид: окна сообщений (справка, подтверждения), системные диалоги «Открыть» / «Сохранить» / «Печать» и ползунки регуляторов.

## Настройки (Kadr.ini)

Все настройки хранятся в `Kadr.ini` рядом с `Kadr.exe`. Если папка доступна только для чтения, Kadr сообщит, что настройки не удаётся сохранить.

```ini
[General]
Language=en      ; pl, en, es, fr, de, pt, ru, uk, it, nl, cs, hu, ro, tr, el, ar, he, hi, bn, ur, zh, ja, ko, id, vi, th, fa, ta, te, mr
Theme=auto       ; auto, light or dark
[Print]
Scale=fit        ; fit, fill, stretch, actual, percent, width or height
```

Язык также можно выбрать в **Ещё (…) → Язык**; изменение вступит в силу после перезапуска Kadr. Тема применяется сразу.

Языки интерфейса: Polski, English, Español, Français, Deutsch, Português, Русский, Українська, Italiano, Nederlands, Čeština, Magyar, Română, Türkçe, Ελληνικά, العربية, עברית, हिन्दी, বাংলা, اردو, 中文, 日本語, 한국어, Bahasa Indonesia, Tiếng Việt, ไทย, فارسی, தமிழ், తెలుగు, मराठी.

## Сборка из исходного кода

Требования: [Zig 0.11.0](https://ziglang.org/download/0.11.0/zig-windows-x86_64-0.11.0.zip), распакованный в `tools\zig-windows-x86_64-0.11.0\` (архив не входит в репозиторий; его SHA-256 указан в `THIRD-PARTY.txt`).

```bat
build.cmd
```

Результат — `Kadr.exe` (цель `x86-windows.xp`, Pentium III, `ReleaseSmall`) с PE-заголовком, совместимым с XP. Пересоздание значка: `tools\build_icon.cmd` (Pillow + windres/objcopy).

Kadr компонуется только с библиотеками, которые есть в Windows XP. Более новые возможности (тёмные заголовки окон, тёмные меню и элементы управления) загружаются во время выполнения через `LoadLibrary` / `GetProcAddress` и пропускаются в старых системах.

## Запуск тестов

- Наборы тестов находятся в подпапках `tests\` (`editor-check`, `print-options`, `loader-check`, `image-check`, `codec-check`, `render-check`, `export-check`); каждый запускается своим `check.cmd`, который собирает и запускает тестовые программы на Zig. `tests\editor-check\check.cmd` выполняет тесты главного окна (включая тесты настройки темы и определения темы), тесты редактора, проверку покрытия языков и пробную сборку x86/XP; `tests\print-options\check.cmd` выполняет тесты печати и компоновки.
- Модульные тесты отдельных модулей можно запустить через `zig test`, например `zig test src\toolbar.zig`, `src\navigation.zig`, `src\image.zig`, `src\zoom.zig`, `src\theme.zig` (с той же целью и теми же флагами include, что и в `check.cmd`).
- Вспомогательные скрипты на Python 3: `python tests\i18n-check\run.py` (выбор языка), `python tests\locale_coverage.py` (все строки интерфейса есть в каталоге для 30 языков), `python tests\audit_xp.py` (проверка импортов и заголовка `Kadr.exe` на совместимость с XP), `tests\measure_print.py`, `tests\tooltip_probe.py`, `tests\shot.py`.
- `tests\generate_fixtures.py` создаёт тестовые изображения (нужен Pillow); он используется только при разработке и никогда — самим `Kadr.exe`.
