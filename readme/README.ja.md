# Kadr

**高速・極小・ポータブルな Windows 用の画像ビューアー兼エディター。Windows XP から Windows 11 まで、1 MB 未満の `Kadr.exe` ひとつで動作します。**

Kadr は [Zig](https://ziglang.org/) で書かれたネイティブな Win32/GDI+ アプリケーションです。インストーラーも .NET も Electron も Node.js も不要で、`Kadr.exe` を好きな場所にコピーして実行するだけです。設定はプログラムと同じ場所の `Kadr.ini` に保存されます（ポータブル — レジストリや AppData には何も書き込みません）。

![Kadr のメインウィンドウ（ライトテーマ）](../docs/screenshots/main-light.png)

## 機能

- **ビューアー** — 写真を開く、フォルダー内の移動（矢印キー、前へ/次へ）、スライドショー、全画面表示、なめらかなズーム（画面に合わせる、1:1、カーソル位置でのマウスホイール、`125%`、`37,5%`、`200×` などの数値入力）、画像のドラッグ移動、アニメーション GIF の再生、複数ページの TIFF と DjVu、EXIF による自動回転。
- **エディター** — ライブ枠と縦横比プリセット（自由、1:1、4:3、3:4、3:2、2:3、16:9、A4 縦/横）によるトリミング、ペン・蛍光ペン・消しゴム・直線・矢印・四角形・テキスト、元に戻す/やり直し、回転と反転、明るさ・コントラスト・彩度・白黒。変更は保存するまでメモリ上に保持されます。
- **印刷** — ライブ印刷プレビュー。用紙サイズ、向き、倍率（全体を収める / 塗りつぶし（切り抜き）/ 引き伸ばし（ページ全体）/ 100% / 任意の % / mm 単位の幅または高さ）、余白、位置、カラーまたはグレースケールを設定できます。
- **ファイル操作** — 保存（回転）、名前を付けて保存、書き出し / 圧縮（PNG、JPEG、BMP、TIFF、GIF。リサイズとサイズの見積もり付き）、画像またはパスのクリップボードへのコピー、名前の変更、ごみ箱への移動または完全な削除、フォルダーに表示、デスクトップの壁紙に設定。
- **対応形式** — PNG、JPEG/JFIF、BMP/DIB、GIF、TIFF、DjVu、ICO、WMF/EMF、TGA、PCX、PSD（統合画像）、PBM/PGM/PPM/PNM、QOI。
- **30 の表示言語** — Windows の言語を自動検出し（該当しない場合は英語）、メニューから変更できます。アラビア語、ヘブライ語、ウルドゥー語、ペルシア語では右から左へのレイアウトになります。
- **テーマ** — ライト、ダーク、または自動（Windows のアプリモードに従い、即座に切り替わります）。
- **小さい** — 1 MB 未満の `Kadr.exe` ひとつだけ。
- **Windows XP 以降** — Windows XP SP3 (x86) から Windows 10/11 まで動作します。

## ダウンロード / インストール

1. [リリースページ](https://github.com/snakex21/kadr/releases)から `Kadr.exe` をダウンロードします（ビルド済みの `Kadr.exe` はリポジトリのルートにも置いてあります）。
2. 書き込み可能な任意のフォルダー（USB メモリなど）に置いて実行します。インストーラーはありません。
3. DjVu ファイルを扱う場合は、リポジトリの `deps\djvu\` フォルダーを `Kadr.exe` と同じ場所に置いてください。

ダブルクリックで画像を開けるようにするには、画像ファイルで Windows の *プログラムから開く → 別のプログラムを選択* を使い、`Kadr.exe` を選びます。

**動作環境:** Windows XP SP3 x86 以降（Windows 10/11 でも動作します）。ほかには何も要りません。

> DjVu デコーダーは古い DjVuLibre 3.5.27 です。信頼できる DjVu ファイルだけを開いてください（詳細は `THIRD-PARTY.txt`）。

## 使い方

- **開く**: **開く** (Ctrl+O)、ウィンドウへのファイルのドラッグ、またはコマンドラインでの指定（`Kadr.exe photo.jpg`）で画像を開きます。
- **移動**: ← / → または矢印ボタンでフォルダー内を移動します。カウンターに現在位置が表示されます（例: `1 / 3`）。矢印キーを押し続けると高速に移動します。
- **ズーム**: マウスホイール（カーソル位置でズーム）、`+` / `−`、**画面に合わせる** (Home)、**1:1** (`1`)、またはズーム欄に値を入力して Enter を押します。画像をドラッグするとスクロールできます。
- **回転**: R / L で回転します。回転するのは表示だけで、**保存** (Ctrl+S) で回転がファイルに書き込まれます。
- **その他 (…)** を押すと、すべてのファイル操作、エディター、印刷、スライドショー、全画面表示、ヘルプ、*更新を確認…*、*テーマ*、*言語* を含むメニューが開きます。
- **更新を確認…** は、プロジェクトの GitHub リリースページを Web ブラウザーで開くだけです。Kadr 自身がインターネットに接続することはありません。

## エディター

エディターは **Edit**（編集、Ctrl+E）で開きます。変更はすべてメモリ上に保持され、保存するまで元のファイルには手を加えません。

- **トリミング** — 8 つのハンドルを持つライブ枠。枠やハンドルをドラッグするか、X / Y / 幅 / 高さをピクセル単位で正確に入力するか、縦横比プリセット（自由、正方形 1:1、4:3、3:4、3:2 (4×6 横)、2:3、16:9、A4 縦、A4 横）を選びます。枠の外側は暗く表示され、**切り抜き** (Enter) でその部分を切り取り、**Whole photo**（写真全体）で枠をリセットします。
- **描画** — ペン、半透明の蛍光ペン、消しゴム（消えるのは描画とテキストだけで、写真は消えません）、直線、矢印、四角形、テキスト。10 色から選べ、太さも調整できます。
- **画像** — 元に戻す / やり直し、左右への 90° 回転、左右反転または上下反転、すべてリセット。
- **色と明るさ** — 明るさ、コントラスト、彩度、白黒。
- **完了** — *適用* で編集した画像をビューアーに戻し、*Save as…* で新しい名前でコピーを保存し、*Print…* で直接印刷プレビューへ進み、*キャンセル* (Esc) で変更を破棄します。

## 印刷

**印刷** (Ctrl+P) を押すと用紙のライブプレビューが開きます。プリンター、用紙（A3–A6、B4/B5、Letter、Legal、Executive、Tabloid、写真サイズ 10×15、13×18、15×20、20×25 cm、4×6、5×7、8×10 in、ユーザー定義またはプリンター固有のサイズ）、向き、カラーまたはグレースケールを選びます。向きは、手動で変更するまで画像に合わせて自動的に決まります。

倍率モード:

| モード | 動作 |
|---|---|
| **画面に合わせる** | 画像全体が余白の内側に収まります。縦横比は維持され、2 辺に白い余白が残ることがあります。 |
| **塗りつぶし / 切り抜き** | 画像が印刷可能領域全体を覆います。縦横比は維持され、はみ出した端は切り取られます。 |
| **Stretch (whole page)**（ページ全体に引き伸ばし） | 画像を印刷可能領域にぴったり引き伸ばします。白い帯は出ませんが、縦横比は維持**されません**。 |
| **100% · 実際のサイズ (96 DPI)** | 1 ピクセル = 1/96 インチ。 |
| **倍率を指定** | 96 DPI を基準に 0.1–1000 %（100% = 上記のサイズ）。 |
| **幅 (mm)** / **高さ (mm)** | 物理的な幅または高さを正確に指定します。もう一方の辺は縦横比に従います。 |

**詳細設定 ▸** を開くと、ユーザー定義の用紙サイズ、余白、用紙上の正確な位置を設定できます（プレビューで画像をドラッグしても構いません。*中央* で中央に戻ります）。灰色の線はプリンターのハードウェア上の印刷限界を示します。最後に選んだ倍率モードは `Kadr.ini` に記憶されます。

## テーマ

**その他 (…) → テーマ** では **ライト**、**ダーク**、**自動**（既定）を選べます。

- **自動** は Windows の *アプリモード*（設定 → 個人用設定 → 色、`AppsUseLightTheme` の値）に従い、Windows 側で変更すると即座に切り替わります。この設定がないシステム（Windows XP、Vista、7、8）では、自動はライトを意味します。
- テーマはメインウィンドウ、ツールバー、ボタンとアイコン、エディター、印刷プレビュー、Kadr 独自のダイアログに適用されます。ダークモードでは画像の背景が濃い灰色になり、Windows 10/11 ではタイトルバーとポップアップメニューも暗くなります。
- Windows ネイティブの一部の要素はシステムの外観のままです: メッセージボックス（ヘルプ、確認）、開く / 保存 / 印刷のシステムダイアログ、スライダーのつまみ。

## 設定 (Kadr.ini)

すべての設定は `Kadr.exe` と同じ場所の `Kadr.ini` に保存されます。フォルダーが読み取り専用の場合は、設定を保存できないことを Kadr が知らせます。

```ini
[General]
Language=en      ; pl, en, es, fr, de, pt, ru, uk, it, nl, cs, hu, ro, tr, el, ar, he, hi, bn, ur, zh, ja, ko, id, vi, th, fa, ta, te, mr
Theme=auto       ; auto, light or dark
[Print]
Scale=fit        ; fit, fill, stretch, actual, percent, width or height
```

言語は **その他 (…) → 言語** からも選べます。変更は Kadr の再起動後に反映されます。テーマはすぐに反映されます。

表示言語: Polski, English, Español, Français, Deutsch, Português, Русский, Українська, Italiano, Nederlands, Čeština, Magyar, Română, Türkçe, Ελληνικά, العربية, עברית, हिन्दी, বাংলা, اردو, 中文, 日本語, 한국어, Bahasa Indonesia, Tiếng Việt, ไทย, فارسی, தமிழ், తెలుగు, मराठी.

## ソースからのビルド

必要なもの: [Zig 0.11.0](https://ziglang.org/download/0.11.0/zig-windows-x86_64-0.11.0.zip) を `tools\zig-windows-x86_64-0.11.0\` に展開しておくこと（アーカイブはリポジトリに含まれていません。SHA-256 は `THIRD-PARTY.txt` に記載されています）。

```bat
build.cmd
```

生成物は XP 互換の PE ヘッダーを持つ `Kadr.exe`（ターゲット `x86-windows.xp`、Pentium III、`ReleaseSmall`）です。アイコンの再生成: `tools\build_icon.cmd`（Pillow + windres/objcopy）。

Kadr がリンクするのは Windows XP に存在するライブラリだけです。新しい機能（暗いタイトルバー、暗いメニューとコントロール）は実行時に `LoadLibrary` / `GetProcAddress` で読み込まれ、古いシステムではスキップされます。

## テストの実行

- テストスイートは `tests\` のサブフォルダー（`editor-check`、`print-options`、`loader-check`、`image-check`、`codec-check`、`render-check`、`export-check`）にあり、それぞれの `check.cmd` で起動します。このスクリプトは Zig のテストハーネスをビルドして実行します。`tests\editor-check\check.cmd` はメインウィンドウのテスト（テーマ設定とテーマ解決のテストを含む）、エディターのテスト、言語カバレッジのチェック、x86/XP 向け候補ビルドを実行し、`tests\print-options\check.cmd` は印刷とレイアウトのテストを実行します。
- 個々のモジュールの単体テストは `zig test` で実行できます。例: `zig test src\toolbar.zig`、`src\navigation.zig`、`src\image.zig`、`src\zoom.zig`、`src\theme.zig`（`check.cmd` と同じターゲットとインクルードフラグを指定）。
- Python 3 の補助スクリプト: `python tests\i18n-check\run.py`（言語選択）、`python tests\locale_coverage.py`（すべての UI 文字列が 30 言語分カタログにあるか）、`python tests\audit_xp.py`（`Kadr.exe` の XP インポート/ヘッダー監査）、`tests\measure_print.py`、`tests\tooltip_probe.py`、`tests\shot.py`。
- `tests\generate_fixtures.py` はテスト画像を生成します（Pillow が必要）。開発専用で、`Kadr.exe` が使うことはありません。
