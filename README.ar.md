# Kadr

**عارض ومحرر صور سريع وصغير جدًا ومحمول لنظام Windows — من Windows XP إلى Windows 11، في ملف `Kadr.exe` واحد أصغر من 1 MB.**

Kadr تطبيق Win32/GDI+ أصلي مكتوب بلغة [Zig](https://ziglang.org/). لا مثبّت، ولا .NET، ولا Electron، ولا Node.js: انسخ `Kadr.exe` إلى أي مكان وشغّله. تُحفظ الإعدادات في `Kadr.ini` بجوار البرنامج (محمول — لا يُكتب شيء في السجل ولا في AppData).

## الميزات

- **العارض** — فتح الصور، والتنقل في المجلد (مفاتيح الأسهم، السابقة/التالية)، وعرض الشرائح، وملء الشاشة، وتكبير سلس (احتواء، 1:1، عجلة الفأرة عند موضع المؤشر، قيم مكتوبة مثل `125%` أو `37,5%` أو `200×`)، وتحريك الصورة، وتشغيل صور GIF المتحركة، وملفات TIFF وDjVu متعددة الصفحات، والاتجاه التلقائي وفق EXIF.
- **المحرر** — اقتصاص بإطار حي ونسب أبعاد جاهزة (حرة، 1:1، 4:3، 3:4، 3:2، 2:3، 16:9، A4 عمودي/أفقي)؛ قلم، وقلم تمييز، وممحاة، وخط، وسهم، ومستطيل، ونص؛ تراجع/إعادة؛ تدوير وقلب؛ سطوع وتباين وتشبع وأبيض وأسود. تبقى التغييرات في الذاكرة حتى تحفظ.
- **الطباعة** — معاينة طباعة حية مع حجم الورق، والاتجاه، والمقياس (احتواء / ملء (مع اقتصاص) / تمديد (الصفحة كاملة) / 100% / نسبة مخصصة / العرض أو الارتفاع بـ mm)، والهوامش، والموضع، والطباعة الملونة أو بتدرج الرمادي.
- **أدوات الملفات** — حفظ (التدوير)، وحفظ باسم، وتصدير / ضغط (PNG وJPEG وBMP وTIFF وGIF) مع تغيير الحجم وتقدير حجم الملف، ونسخ الصورة أو المسار إلى الحافظة، وإعادة التسمية، والنقل إلى سلة المحذوفات أو الحذف النهائي، والإظهار في المجلد، والتعيين كخلفية لسطح المكتب.
- **التنسيقات** — PNG، JPEG/JFIF، BMP/DIB، GIF، TIFF، DjVu، ICO، WMF/EMF، TGA، PCX، PSD (صورة مدمجة)، PBM/PGM/PPM/PNM، QOI.
- **30 لغة للواجهة** — تُكتشف لغة Windows تلقائيًا (وإلا تُستخدم الإنجليزية) ويمكن تغييرها من القائمة؛ تخطيط من اليمين إلى اليسار للعربية والعبرية والأردية والفارسية.
- **السمات** — فاتحة أو داكنة أو تلقائية (تتبع وضع التطبيقات في Windows وتتبدل فورًا).
- **صغير الحجم** — ملف `Kadr.exe` واحد أصغر من 1 MB.
- **Windows XP وما بعده** — يعمل من Windows XP SP3 (x86) حتى Windows 10/11.

## التنزيل / التثبيت

1. نزّل `Kadr.exe` من [صفحة الإصدارات](https://github.com/snakex21/kadr/releases) (توجد أيضًا نسخة جاهزة من `Kadr.exe` في جذر المستودع).
2. ضعه في أي مجلد يمكنك الكتابة فيه (مثل ذاكرة USB) وشغّله. لا يوجد مثبّت.
3. لملفات DjVu، أبقِ مجلد `deps\djvu\` من المستودع بجوار `Kadr.exe`.

لفتح الصور بنقرة مزدوجة، استخدم في Windows الأمر *فتح باستخدام → اختيار تطبيق آخر* على صورة واختر `Kadr.exe`.

**المتطلبات:** Windows XP SP3 x86 أو أحدث (يعمل أيضًا على Windows 10/11). لا شيء غير ذلك.

> مفكك ترميز DjVu هو الإصدار القديم DjVuLibre 3.5.27 — لا تفتح إلا ملفات DjVu التي تثق بها (التفاصيل في `THIRD-PARTY.txt`).

## الاستخدام

- **افتح** صورة باستخدام **فتح** (Ctrl+O)، أو بسحب ملف إلى النافذة، أو بتمريره في سطر الأوامر: `Kadr.exe photo.jpg`.
- **تصفّح** المجلد باستخدام ← / → أو أزرار الأسهم؛ يعرض العدّاد الموضع (مثل `1 / 3`). اضغط مع الاستمرار على مفتاح سهم للتصفح بسرعة.
- **كبّر وصغّر** بعجلة الفأرة (التكبير عند موضع المؤشر)، أو `+` / `−`، أو **احتواء** (Home)، أو **1:1** (`1`)، أو اكتب قيمة في حقل التكبير واضغط Enter. اسحب الصورة لتحريكها.
- **دوّر** باستخدام R / L. يُدوَّر العرض؛ ويكتب **حفظ** (Ctrl+S) التدوير في الملف.
- يفتح **المزيد (…)** القائمة التي تضم جميع عمليات الملفات، والمحرر، والطباعة، وعرض الشرائح، وملء الشاشة، والمساعدة، و*التحقق من التحديثات…*، و*السمة*، و*اللغة*.
- لا يفعل **التحقق من التحديثات…** سوى فتح صفحة إصدارات المشروع على GitHub في متصفح الويب — فـ Kadr نفسه لا يتصل بالإنترنت أبدًا.

## المحرر

افتح المحرر باستخدام **Edit** (تحرير، Ctrl+E). تبقى جميع التغييرات في الذاكرة؛ ولا يُمَس الملف الأصلي حتى تحفظ.

- **قص** — إطار حي بثمانية مقابض؛ اسحب الإطار أو مقابضه، أو اكتب قيم X / Y / العرض / الارتفاع بدقة بالبكسل، أو اختر نسبة أبعاد جاهزة (حرة، مربع 1:1، 4:3، 3:4، 3:2 (4×6 أفقي)، 2:3، 16:9، A4 عمودي، A4 أفقي). تُعتَّم المنطقة خارج الإطار؛ ويقطعها **اقتصاص** (Enter)، ويعيد **Whole photo** (الصورة كاملة) ضبط الإطار.
- **الرسم** — قلم، وقلم تمييز شبه شفاف، وممحاة (تمسح الرسوم والنصوص فقط، ولا تمس الصورة أبدًا)، وخط مستقيم، وسهم، ومستطيل، ونص، مع عشرة ألوان وسُمك قابل للضبط.
- **Image** (الصورة) — تراجع / إعادة، وتدوير بمقدار 90° لليسار أو لليمين، وانعكاس أفقي أو عمودي، وإعادة تعيين الكل.
- **Colour and light** (اللون والإضاءة) — السطوع والتباين والتشبع والأبيض والأسود.
- **الإنهاء** — يعيد *تطبيق* الصورة المحررة إلى العارض، ويحفظ *Save as…* (حفظ باسم) نسخة باسم جديد، وينتقل *Print…* (طباعة) مباشرة إلى معاينة الطباعة، ويتجاهل *إلغاء* (Esc) التغييرات.

## الطباعة

يفتح **طباعة** (Ctrl+P) معاينة حية للورقة. اختر الطابعة، والورق (A3–A6، B4/B5، Letter، Legal، Executive، Tabloid، مقاسات الصور 10×15، 13×18، 15×20، 20×25 cm، 4×6، 5×7، 8×10 in، أو مقاسًا مخصصًا أو مقاس الطابعة نفسها)، والاتجاه، والطباعة الملونة أو بتدرج الرمادي. يتبع الاتجاه الصورة تلقائيًا إلى أن تغيّره.

أوضاع المقياس:

| الوضع | ما يفعله |
|---|---|
| **احتواء** | تتسع الصورة بأكملها داخل الهوامش؛ تُحفظ النسب وقد تبقى مساحة بيضاء على جانبين. |
| **ملء / اقتصاص** | تغطي الصورة كامل المساحة القابلة للطباعة؛ تُحفظ النسب وتُقتص الحواف الزائدة. |
| **Stretch (whole page)** (تمديد على الصفحة كاملة) | تُمدَّد الصورة لتطابق المساحة القابلة للطباعة تمامًا — بلا أشرطة بيضاء، لكن النسب **لا** تُحفظ. |
| **100% · الحجم الفعلي (96 DPI)** | بكسل واحد = 1/96 بوصة. |
| **نسبة مخصصة** | 0.1–1000 % نسبةً إلى 96 DPI (100% = الحجم في السطر السابق). |
| **العرض / الارتفاع (mm)** | عرض أو ارتفاع فعلي دقيق؛ ويُحسب الجانب الآخر وفق النسب. |

يضيف **متقدم ▸** حجم ورق مخصصًا وهوامش وموضعًا دقيقًا على الورقة (أو اسحب الصورة في المعاينة؛ ويعيدها *توسيط* إلى المنتصف). يُظهر الخط الرمادي الحد المادي للطابعة. يُحفظ آخر وضع مقياس مختار في `Kadr.ini`.

## السمات

يوفّر **المزيد (…) → السمة** الخيارات **فاتح** و**داكن** و**تلقائي** (الافتراضي).

- يتبع **تلقائي** *وضع التطبيقات* في Windows (الإعدادات → التخصيص → الألوان، القيمة `AppsUseLightTheme`) ويتبدل فورًا عندما تغيّره في Windows. في الأنظمة التي لا تحتوي على هذا الإعداد (Windows XP وVista و7 و8) يعني تلقائي السمة الفاتحة.
- تشمل السمة النافذة الرئيسية، وشريط الأدوات، والأزرار والأيقونات، والمحرر، ومعاينة الطباعة، ومربعات الحوار الخاصة بـ Kadr. في الوضع الداكن تكون خلفية الصورة رمادية داكنة، وفي Windows 10/11 تصبح أشرطة العناوين والقوائم المنبثقة داكنة أيضًا.
- تحتفظ بعض عناصر Windows الأصلية بمظهر النظام: مربعات الرسائل (المساعدة، التأكيدات)، ومربعات حوار النظام فتح / حفظ / طباعة، ومقابض أشرطة التمرير.

## الإعدادات (Kadr.ini)

تُحفظ جميع الإعدادات في `Kadr.ini` بجوار `Kadr.exe`. إذا كان المجلد للقراءة فقط، فسيخبرك Kadr بأنه لا يمكن حفظ الإعدادات.

</div>

```ini
[General]
Language=en      ; pl, en, es, fr, de, pt, ru, uk, it, nl, cs, hu, ro, tr, el, ar, he, hi, bn, ur, zh, ja, ko, id, vi, th, fa, ta, te, mr
Theme=auto       ; auto, light or dark
[Print]
Scale=fit        ; fit, fill, stretch, actual, percent, width or height
```

## تشغيل الاختبارات

- توجد مجموعات الاختبارات في مجلدات فرعية ضمن `tests\` (`editor-check`، `print-options`، `loader-check`، `image-check`، `codec-check`، `render-check`، `export-check`)؛ وتُشغَّل كل منها عبر `check.cmd` الخاص بها، الذي يبني برامج اختبار Zig ويشغّلها. يشغّل `tests\editor-check\check.cmd` اختبارات النافذة الرئيسية (بما فيها اختبارات إعداد السمة وتحديد السمة)، واختبارات المحرر، وفحص تغطية اللغات، وبناءً تجريبيًا لـ x86/XP؛ ويشغّل `tests\print-options\check.cmd` اختبارات الطباعة والتخطيط.
- يمكن تشغيل اختبارات الوحدات في وحدات منفردة باستخدام `zig test`، مثل `zig test src\toolbar.zig`، `src\navigation.zig`، `src\image.zig`، `src\zoom.zig`، `src\theme.zig` (بالهدف نفسه وخيارات التضمين نفسها كما في `check.cmd`).
- أدوات مساعدة بلغة Python 3: `python tests\i18n-check\run.py` (اختيار اللغة)، `python tests\locale_coverage.py` (جميع نصوص الواجهة موجودة في الكتالوج لـ 30 لغة)، `python tests\audit_xp.py` (تدقيق الاستيرادات والترويسة في `Kadr.exe` للتوافق مع XP)، `tests\measure_print.py`، `tests\tooltip_probe.py`، `tests\shot.py`.
- ينشئ `tests\generate_fixtures.py` صور اختبار (يتطلب Pillow)؛ ويُستخدم أثناء التطوير فقط، ولا يستخدمه `Kadr.exe` أبدًا.
