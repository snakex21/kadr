# Kadr

**Швидкий, крихітний і портативний переглядач та редактор фотографій для Windows — від Windows XP до Windows 11, в одному файлі `Kadr.exe` розміром менше 1 MB.**

Kadr — нативна програма Win32/GDI+, написана мовою [Zig](https://ziglang.org/). Без інсталятора, без .NET, без Electron, без Node.js: скопіюйте `Kadr.exe` куди завгодно й запустіть. Налаштування зберігаються у файлі `Kadr.ini` поруч із програмою (портативно — нічого не записується ні до реєстру, ні до AppData).

## Можливості

- **Переглядач** — відкриття фотографій, перегляд теки (клавіші зі стрілками, попереднє/наступне), показ слайдів, повний екран, плавне масштабування (вписування, 1:1, коліщатко миші в точці курсора, введені значення на кшталт `125%`, `37,5%` або `200×`), перетягування зображення, відтворення анімованих GIF, багатосторінкові TIFF і DjVu, автоматична орієнтація за EXIF.
- **Редактор** — обрізання з живою рамкою та готовими пропорціями (довільні, 1:1, 4:3, 3:4, 3:2, 2:3, 16:9, A4 книжкова/альбомна); пензель, маркер, гумка, лінія, стрілка, прямокутник і текст; скасування/повторення дії; поворот і віддзеркалення; яскравість, контраст, насиченість і чорно-біле зображення. Зміни залишаються в пам’яті, доки ви їх не збережете.
- **Друк** — живий попередній перегляд друку з розміром паперу, орієнтацією, масштабом (вписати / заповнити (обрізати) / розтягнути (на всю сторінку) / 100% / власний % / ширина або висота в mm), полями, положенням, кольоровим друком або відтінками сірого.
- **Робота з файлами** — збереження (повороту), збереження як, експорт / стиснення (PNG, JPEG, BMP, TIFF, GIF) зі зміною розміру й оцінкою розміру файлу, копіювання зображення або шляху до буфера обміну, перейменування, переміщення до Кошика або остаточне видалення, показ у теці, встановлення тлом стільниці.
- **Формати** — PNG, JPEG/JFIF, BMP/DIB, GIF, TIFF, DjVu, ICO, WMF/EMF, TGA, PCX, PSD (зведене зображення), PBM/PGM/PPM/PNM, QOI.
- **30 мов інтерфейсу** — мова Windows визначається автоматично (за замовчуванням — англійська), її можна змінити в меню; розкладка справа наліво для арабської, івриту, урду та перської.
- **Теми** — світла, темна або автоматична (відповідає режиму застосунків Windows і перемикається на льоту).
- **Мініатюрність** — один `Kadr.exe` розміром менше 1 MB.
- **Windows XP і новіші** — працює від Windows XP SP3 (x86) до Windows 10/11.

## Завантаження / встановлення

1. Завантажте `Kadr.exe` зі [сторінки випусків](https://github.com/snakex21/kadr/releases) (готовий `Kadr.exe` також лежить у корені репозиторію).
2. Покладіть його в будь-яку теку, до якої маєте право запису (наприклад, на флешку), і запустіть. Інсталятора немає.
3. Для файлів DjVu тримайте теку `deps\djvu\` з репозиторію поруч із `Kadr.exe`.

Щоб відкривати зображення подвійним клацанням, скористайтеся в Windows командою *Відкрити за допомогою → Вибрати іншу програму* на файлі зображення й виберіть `Kadr.exe`.

**Вимоги:** Windows XP SP3 x86 або новіша (Windows 10/11 теж підходять). Більше нічого.

> Декодер DjVu — це старіша версія DjVuLibre 3.5.27, тож відкривайте лише ті файли DjVu, яким довіряєте (подробиці в `THIRD-PARTY.txt`).

## Використання

- **Відкрийте** зображення кнопкою **Відкрити** (Ctrl+O), перетягнувши файл у вікно або передавши його в командному рядку: `Kadr.exe photo.jpg`.
- **Гортайте** теку клавішами ← / → або кнопками зі стрілками; лічильник показує позицію (наприклад, `1 / 3`). Утримуйте клавішу зі стрілкою, щоб гортати швидко.
- **Масштабуйте** коліщатком миші (масштабування в точці курсора), клавішами `+` / `−`, кнопками **Вписати** (Home), **1:1** (`1`) або введіть значення в поле масштабу й натисніть Enter. Перетягуйте зображення, щоб його зсунути.
- **Повертайте** клавішами R / L. Повертається лише вигляд; **Зберегти** (Ctrl+S) записує поворот у файл.
- **Більше (…)** відкриває меню з усіма операціями над файлами, редактором, друком, показом слайдів, повним екраном, довідкою, пунктами *Перевірити оновлення…*, *Тема* і *Мова*.
- **Перевірити оновлення…** лише відкриває сторінку випусків проєкту на GitHub у вашому браузері — сам Kadr ніколи не підключається до інтернету.

## Редактор

Редактор відкривається кнопкою **Edit** («Редагувати», Ctrl+E). Усі зміни зберігаються в пам’яті; оригінальний файл не змінюється, доки ви не збережете результат.

- **Обрізання** — жива рамка з вісьмома маркерами; перетягуйте рамку або маркери, введіть точні X / Y / ширину / висоту в пікселях або виберіть готову пропорцію (довільна, квадрат 1:1, 4:3, 3:4, 3:2 (4×6 альбомна), 2:3, 16:9, A4 книжкова, A4 альбомна). Область поза рамкою затемнюється; **Обрізати** (Enter) відрізає її, а **Whole photo** (усе фото) скидає рамку.
- **Малювання** — пензель, напівпрозорий маркер, гумка (стирає лише малюнки й текст, ніколи саме фото), пряма лінія, стрілка, прямокутник і текст, з десятьма кольорами та регульованою товщиною.
- **Зображення** — скасувати / повторити, поворот на 90° ліворуч або праворуч, віддзеркалення по горизонталі або вертикалі, скинути все.
- **Колір і світло** — яскравість, контраст, насиченість і чорно-біле зображення.
- **Завершення** — *Застосувати* повертає відредаговане зображення до переглядача, *Save as…* зберігає копію під новою назвою, *Print…* одразу переходить до попереднього перегляду друку, *Скасувати* (Esc) відкидає зміни.

## Друк

**Друк** (Ctrl+P) відкриває живий попередній перегляд аркуша. Виберіть принтер, папір (A3–A6, B4/B5, Letter, Legal, Executive, Tabloid, фотоформати 10×15, 13×18, 15×20, 20×25 cm, 4×6, 5×7, 8×10 in, власний або визначений принтером), орієнтацію та кольоровий друк чи відтінки сірого. Орієнтація автоматично підлаштовується під зображення, доки ви не зміните її вручну.

Режими масштабу:

| Режим | Що робить |
|---|---|
| **Вписати** | Усе зображення вміщується в поля; пропорції зберігаються, з двох боків можуть лишитися білі смуги. |
| **Заповнити / обрізати** | Зображення покриває всю область друку; пропорції зберігаються, а краї, що виходять за межі, обрізаються. |
| **Stretch (whole page)** (розтягнути на всю сторінку) | Зображення розтягується точно на область друку — без білих смуг, але пропорції **не** зберігаються. |
| **100% · Початковий розмір (96 DPI)** | Один піксель = 1/96 дюйма. |
| **Власний відсоток** | 0,1–1000 % відносно 96 DPI (100% = розмір вище). |
| **Ширина (mm)** / **Висота (mm)** | Точна фізична ширина або висота; другий бік визначається пропорціями. |

**Додатково ▸** додає власний розмір паперу, поля й точне положення на аркуші (або перетягніть зображення в попередньому перегляді; *По центру* повертає його в середину). Сіра лінія показує апаратну межу принтера. Останній вибраний режим масштабу запам’ятовується в `Kadr.ini`.

## Теми

**Більше (…) → Тема** пропонує **Світла**, **Темна** та **Автоматично** (за замовчуванням).

- **Автоматично** відповідає *режиму застосунків* Windows (Параметри → Персоналізація → Кольори, значення `AppsUseLightTheme`) і перемикається на льоту, коли ви змінюєте його в Windows. У системах без цього параметра (Windows XP, Vista, 7, 8) «Автоматично» означає «Світла».
- Тема охоплює головне вікно, панель інструментів, кнопки та значки, редактор, попередній перегляд друку й власні діалогові вікна Kadr. У темному режимі тло зображення темно-сіре, а у Windows 10/11 заголовки вікон і спливні меню теж темні.
- Кілька нативних елементів Windows зберігають системний вигляд: вікна повідомлень (довідка, підтвердження), системні діалоги Відкрити / Зберегти / Друк і повзунки регуляторів.

## Налаштування (Kadr.ini)

Усі налаштування зберігаються у файлі `Kadr.ini` поруч із `Kadr.exe`. Якщо тека доступна лише для читання, Kadr повідомить, що налаштування не вдається зберегти.

```ini
[General]
Language=en      ; pl, en, es, fr, de, pt, ru, uk, it, nl, cs, hu, ro, tr, el, ar, he, hi, bn, ur, zh, ja, ko, id, vi, th, fa, ta, te, mr
Theme=auto       ; auto, light or dark
[Print]
Scale=fit        ; fit, fill, stretch, actual, percent, width or height
```

Мову також можна вибрати через **Більше (…) → Мова**; зміна набуде чинності після перезапуску Kadr. Тема застосовується одразу.

Мови інтерфейсу: Polski, English, Español, Français, Deutsch, Português, Русский, Українська, Italiano, Nederlands, Čeština, Magyar, Română, Türkçe, Ελληνικά, العربية, עברית, हिन्दी, বাংলা, اردو, 中文, 日本語, 한국어, Bahasa Indonesia, Tiếng Việt, ไทย, فارسی, தமிழ், తెలుగు, मराठी.

## Збирання з вихідного коду

Вимоги: [Zig 0.11.0](https://ziglang.org/download/0.11.0/zig-windows-x86_64-0.11.0.zip), розпакований у `tools\zig-windows-x86_64-0.11.0\` (архів не входить до репозиторію; його SHA-256 наведено в `THIRD-PARTY.txt`).

```bat
build.cmd
```

Результат — `Kadr.exe` (ціль `x86-windows.xp`, Pentium III, `ReleaseSmall`) із сумісним з XP заголовком PE. Перегенерування значка: `tools\build_icon.cmd` (Pillow + windres/objcopy).

Kadr компонується лише з бібліотеками, які є у Windows XP. Новіші можливості (темні заголовки вікон, темні меню й елементи керування) завантажуються під час виконання через `LoadLibrary` / `GetProcAddress` і пропускаються на старіших системах.

## Запуск тестів

- Набори тестів лежать у підтеках `tests\` (`editor-check`, `print-options`, `loader-check`, `image-check`, `codec-check`, `render-check`, `export-check`); кожен запускається своїм `check.cmd`, який збирає й запускає тестові програми на Zig. `tests\editor-check\check.cmd` запускає тести головного вікна (зокрема тести налаштування та визначення теми), тести редактора, перевірку покриття мов і пробне збирання для x86/XP; `tests\print-options\check.cmd` запускає тести друку й компонування сторінки.
- Модульні тести окремих модулів можна запустити через `zig test`, наприклад `zig test src\toolbar.zig`, `src\navigation.zig`, `src\image.zig`, `src\zoom.zig`, `src\theme.zig` (з тією самою ціллю та тими самими прапорцями include, що й у `check.cmd`).
- Допоміжні скрипти Python 3: `python tests\i18n-check\run.py` (вибір мови), `python tests\locale_coverage.py` (усі рядки інтерфейсу є в каталозі для 30 мов), `python tests\audit_xp.py` (аудит імпортів і заголовка XP у `Kadr.exe`), `tests\measure_print.py`, `tests\tooltip_probe.py`, `tests\shot.py`.
- `tests\generate_fixtures.py` створює тестові зображення (потрібен Pillow); він використовується лише під час розробки й ніколи — самим `Kadr.exe`.
